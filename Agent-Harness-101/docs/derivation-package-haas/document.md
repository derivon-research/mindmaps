# 将 Harness 包装为 Harness-as-a-Service

[Agent Harness](../concept-agent-harness/index.html) 已包含 Loop、Tool、Context、编排和权限等运行决策；当 SDK 或托管平台提供这些能力与默认值作为可配置 runtime 时，就形成 [Harness-as-a-Service](../concept-harness-as-a-service/index.html)，使使用者直接获得可运行 v0.1。

权重 1.5：主要是工程包装和责任转移，需要少量产品层解释。

来源：同章 §7.1，revision 297。

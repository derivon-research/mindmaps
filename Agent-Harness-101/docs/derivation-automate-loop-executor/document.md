# 从手工接力构造 Loop Engineering

[手工 Agent 循环](../concept-manual-agent-loop/index.html)已经包含行动与人工复查；[Self-prompting](../concept-self-prompting/index.html) 替代人生成下一轮入口；[Acceptance Criteria](../concept-acceptance-criteria/index.html) 给出收敛靶子；[跨会话记忆](../concept-cross-session-memory/index.html)保存进度。四者共同把“每轮都要人工接力”的循环改造成 Agent 可持续执行的 [Loop Engineering](../concept-loop-engineering/index.html)。

权重 4.0：这是本章的核心概念桥梁。高权重复核：人工循环、续写机制、验收和记忆已分别拆点，剩余步骤就是执行者替换这一完整构造。

来源：同章 §1-3 与 §8，revision 1389。

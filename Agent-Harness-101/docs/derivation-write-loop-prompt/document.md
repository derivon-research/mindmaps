# 把目标、验收和循环条件写成 Loop Prompt

[有界目标](../concept-bounded-goal/index.html)说明要做什么；[Acceptance Criteria](../concept-acceptance-criteria/index.html) 列出全部完成条件；[循环条件](../concept-loop-condition/index.html)写明失败后的重试规则。把三者明确表达在 Prompt 中，即得到来源示例的 [Loop Prompt](../concept-loop-prompt/index.html) 骨架。

权重 1.5：主要是结构化表达，只有少量协议组织成本。

来源：同章 §5.3，revision 1389。

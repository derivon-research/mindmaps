# Harness 模式收敛

Harness 模式收敛是来源对多个 [Coding Agent](../concept-coding-agent/index.html) 产品的观察：尽管底层模型不同，它们越来越多地采用文件系统记忆、Shell、[Sandbox](../concept-sandbox/index.html)/审批、计划执行分离、[Sub-Agent](../concept-sub-agent/index.html) 与 [Hook](../concept-hook/index.html) 等相似模式。

这是当前行业观察而非已证明的永久定律；产品实现和边界仍会变化。

来源：同章 §7.3，revision 297。

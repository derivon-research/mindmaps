# 组装 Memory Substrate

[可回放记忆摄取](../concept-replayable-memory-ingestion/index.html)提供可修订历史，[混合记忆检索](../concept-hybrid-memory-retrieval/index.html)把事实带回上下文，Policy Layer贯穿可见与行动边界。三者共同建立 [Company Brain](../concept-company-brain/index.html) 的 [Memory Substrate](../concept-memory-substrate/index.html)。

权重 3.5：这是从组件到基础设施的实质组合。高权重复核：摄取、检索和策略已拆点，没有把聊天框当作底层系统。

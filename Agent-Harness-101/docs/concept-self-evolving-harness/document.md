# Self-evolving Harness

Self-evolving Harness 是一个以运行证据驱动持续改进的闭环：[Tracing](../concept-tracing/index.html) 采集 trajectory，[Evals](../concept-evals/index.html) 识别短板，[Feedback Loop](../concept-feedback-loop/index.html) 把短板回流到 Prompting、Skills 或 Hooks，下一轮 [Agent Loop](../concept-agent-loop/index.html) 使用更新后的 Harness。

“自演进”在本章中不是无监督自我修改的承诺，而是可观察、可评测、可反馈的工程闭环。

来源：同章 §2.1，revision 2846。

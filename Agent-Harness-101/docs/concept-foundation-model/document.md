# Foundation Model

Foundation Model 是 [Agent 系统](../concept-agent-system/index.html)中提供推理与生成能力的模型权重部分。它决定可达到的能力上限，但不直接决定工具如何注册、上下文如何装配、权限如何执行或多 Agent 如何调度。

边界：本 Mindmap 用它指与 Harness 相对的“模型本体”，不展开模型训练、数据集或权重优化。

来源：飞书教程《Harness 101：模型之外的全部》，revision 297，§2 与 §9，https://my.feishu.cn/wiki/Y5jYww4MLiL1ulkwTL6cf6Drnbc

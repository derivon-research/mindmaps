# 手工 Agent 循环

手工 Agent 循环是由人反复完成“写 Prompt → 等 Agent 产出 → 阅读与判断 → 写下一条 Prompt”的工作方式。发现、行动和检查都存在，但负责决定“再来一轮”的循环执行者是人。

主要代价不是循环无效，而是人必须持续轮询结果，频繁切换注意力，Agent 每轮结束后都等待人工接力。

# Manifest 与权限形成 Plugin Audit Surface

[Harness Plugin](../concept-harness-plugin/index.html) 聚合多种扩展；[Plugin Manifest](../concept-plugin-manifest/index.html) 声明装配位置和权限请求；[Memory Permission](../concept-memory-permission/index.html) 提供按资源授权语义。三者共同形成 [Plugin Audit Surface](../concept-plugin-audit-surface/index.html)。

权重 3.0：需要分别审查四类影响面。来源：同章 §7.3，revision 227。

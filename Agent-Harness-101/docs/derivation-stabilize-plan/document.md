# Briefing 与 Nudge 共同稳定计划执行

## 推导

[Plan-then-Act](../concept-plan-then-act/index.html) 给出计划骨架；前置 Briefing 修正输入侧，让陌生主题的计划建立在一次初步认知上；[Nudge](../concept-nudge/index.html) 修正执行侧，在 TODO 未完成时把注意力拉回计划维护。三者共同降低“计划起点跑偏”和“计划中途失效”两类不同风险，从而建立[稳定的计划执行](../concept-reliable-plan-execution/index.html)。

## 学习成本

权重 2.5：需要区分两个失效面并把两个局部补丁放到对应生命周期位置，属于 routine 以上的组合。

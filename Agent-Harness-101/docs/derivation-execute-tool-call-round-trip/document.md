# 完成 Tool Call 往返

[Tool Call](../concept-tool-call/index.html) 表达模型的结构化调用意图，[Harness Tool 执行](../concept-harness-tool-execution/index.html)负责验单并作用于真实环境，[Tool Result](../concept-tool-result/index.html) 把事实回填下一轮。三者联合完成一次 [Tool Call 往返](../concept-tool-call-round-trip/index.html)。

权重 2.5：需要明确意图、执行和事实三层不能互相替代。

来源：§5.2-5.4 与 §6.1，revision 167。

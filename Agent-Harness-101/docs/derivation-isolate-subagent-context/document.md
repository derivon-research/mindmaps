# 独立 Worker 与 Fan-In 建立 Sub-Agent Context Isolation

[Sub-Agent](../concept-sub-agent/index.html) 在独立窗口执行；Fan-In 只把结果带回主线；[Structured Output](../concept-structured-output/index.html) 限定返回形态。三者共同建立 [Sub-Agent Context Isolation](../concept-subagent-context-isolation/index.html)。

权重 3.0：需区分计算轨迹与汇总契约。来源：同章 §2.1，revision 174。

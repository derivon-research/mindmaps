# 在冷启动回收旧 Thinking Block

## 推导

[Thinking Block](../concept-thinking-block/index.html) 提供可裁剪对象；[Idle Gap Trigger](../concept-idle-gap-trigger/index.html) 表示连续缓存已过期、即将重建。此时删除旧块并保留最近轮次，得到 [Thinking Block 回收](../concept-thinking-block-reclamation/index.html)策略。

## 学习成本

权重 2.5：标准时机选择，但需保留“结论不等于完整推理”的损失边界。

# Semantic File System

Semantic File System 让 Artifact 不只是路径中的 Blob，而成为有类型、元数据、稳定路径和可查询属性的对象。

Markdown、Frontmatter、Wikilink 与 Embedding 可组成低成本组织记忆载体。

它与 AFS 不等同：Semantic File System 关注组织知识的意义与关系；AFS 关注异构资源的统一 I/O 和派发。二者可以叠加，但互不推出。

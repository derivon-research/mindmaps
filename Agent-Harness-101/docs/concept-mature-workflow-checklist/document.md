# 成熟 Workflow 检查表

成熟 Workflow 检查表用 Trigger、Planner、State、Workers、Evaluator、Loop、Branch、Resume 与 Repeatability 逐项审视长任务设计。

这不是说每条 Workflow 都必须集齐所有部件：简单 loop 可以没有 Branch 或 Resume；来源只指出 Trigger、Workers、Evaluator 几乎是标配。该点记录的是完整设计审查状态，而不是全部 [Dynamic Workflow](../concept-dynamic-workflow/index.html) 的必要定义。

# 开放目标、自主选向与预算上限构成 Open Loop

[开放目标](../concept-open-ended-goal/index.html)允许继续发现新方向；[Agent 自主选向](../concept-agent-self-direction/index.html)决定当前探索；[外部预算上限](../concept-budget-cap/index.html)限制无明确终点时的最坏开销。三者共同形成探索面广但成本难预估的 [Open Loop](../concept-open-loop/index.html)。

权重 3.0：要同时理解探索自由与外部资源约束，属于非显然的运行边界组合。

来源：同章 §4.1，revision 1389。

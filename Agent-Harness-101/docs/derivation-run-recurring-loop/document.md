# 周期触发、外置记忆与条件判断构成周期性 Loop

[周期触发](../concept-periodic-trigger/index.html)决定何时启动；[跨会话记忆](../concept-cross-session-memory/index.html)恢复上轮状态；[循环条件](../concept-loop-condition/index.html)决定本轮是否继续或暂停；[历史去重](../concept-historical-deduplication/index.html)避免重复处理。四者共同让工作跨周/月反复运行而不每次从零开始。

权重 3.0：需要跨时间连接触发、状态和终止，并处理历史重复。

来源：同章 §6-7，revision 1389。

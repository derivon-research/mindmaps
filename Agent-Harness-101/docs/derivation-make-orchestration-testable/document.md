# 把编排变成可测试对象

[Workflow Script](../concept-workflow-script/index.html) 暴露控制流 Diff，[JSON Schema 输出契约](../concept-json-schema-contract/index.html)暴露中间接口，[Tracing](../concept-tracing/index.html) 记录真实运行，[Evals](../concept-evals/index.html) 用固定样本比较改动前后。四者共同形成[可测试编排](../concept-testable-orchestration/index.html)，让 [Loop Engineering](../concept-loop-engineering/index.html) 不只修改 Prompt 措辞。

权重 3.5：这是从概率行为优化跨到普通软件工程的关键桥梁。高权重复核：代码、接口、观测和回归均已拆点，边只完成可测试闭环的组合。

来源：§1.3 与 §7.1，revision 1503。

# 完成合同

完成合同是在执行前由生成侧与评测侧共同明确的验收标准，例如必须通过哪些测试、覆盖哪些边界、达到哪个 benchmark。

它把“完成”从任务末尾的主观感觉转为开工前可检查的约束，避免评价标准临时漂移。

[Agent Install Contract](../concept-agent-install-contract/index.html) 是领域化完成合同：除成功标准外，还明确安全规则、路径分支、进度和 [Setup Boundary](../concept-setup-boundary/index.html)。

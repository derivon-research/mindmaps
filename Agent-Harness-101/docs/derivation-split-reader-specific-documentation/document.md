# 人类 README 与 Agent 契约形成 Reader-Specific Documentation

[Human-Oriented README](../concept-human-oriented-readme/index.html) 服务理解和选择；[Machine-Executable Document](../concept-machine-executable-document/index.html) 服务条件执行。两类读者目标不同且长期并存，因此应形成 [Reader-Specific Documentation](../concept-reader-specific-documentation/index.html)，而非互相替代。

权重 2.5：需要按读者任务划分职责并共享事实来源。来源：同章 §1、§3，revision 118。

# 用契约界定 Agent 阶段

[Structured Output](../concept-structured-output/index.html) 给出机器可消费的结果形状，[Acceptance Criteria](../concept-acceptance-criteria/index.html) 给出质量和失败出口。两者共同把开放 Agent 能力收敛成[有边界的 Agent 阶段](../concept-bounded-agent-stage/index.html)。

权重 2.0：这是输出接口与验收标准的直接组合，但需要避免把“结构正确”误当成“语义正确”。

来源：§3.2 与 §7.2，revision 1503。

# 建立 Workflow 人工介入

[Workflow 主动询问](../concept-workflow-initiated-question/index.html)让脚本在关键岔路请求决定；[Steering Inbox](../concept-steering-inbox/index.html) 让用户在运行途中主动纠偏；[Human-in-the-loop](../concept-human-in-the-loop/index.html) 界定哪些判断不应由自动化独占。三者共同建立双向、按需的人工介入机制。

权重 2.5：需要协调两种方向相反的消息通道，并保持人工只在关键点介入。三个尾点各自不可替代。

来源：§6，revision 927。

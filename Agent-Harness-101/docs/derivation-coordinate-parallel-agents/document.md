# Orchestrator 通过 Fan-out/Fan-in 编排 Sub-Agent

[Orchestrator](../concept-orchestrator/index.html) 掌管目标；[Sub-Agent](../concept-sub-agent/index.html) 承担局部职责；[Fan-out](../concept-fan-out/index.html) 并行分发独立任务；[Fan-in](../concept-fan-in/index.html) 汇总结果并恢复统一验收面。四者共同形成[并行 Agent 编排](../concept-parallel-agent-orchestration/index.html)。

权重 3.0：需要理解散开与收口的对称结构及各角色边界，但不包含额外调度算法。

来源：同章 §3.2、§5.1 与 §6，revision 1389。

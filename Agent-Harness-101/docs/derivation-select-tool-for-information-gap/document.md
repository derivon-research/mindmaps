# 为外部信息缺口选择 Tool

[外部信息缺口](../concept-external-information-gap/index.html)说明当前 Context 缺少实时或环境事实，[Tool Definition 契约](../concept-tool-definition-contract/index.html)给出哪项能力可以补齐以及如何调用。模型据此生成 [Tool Call](../concept-tool-call/index.html) 意图。

权重 2.5：这是语义匹配而非确定路由；两尾分别贡献需求和能力边界。

来源：§5.3 与 §6.1，revision 167。

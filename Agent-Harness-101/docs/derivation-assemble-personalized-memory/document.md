# 多种记忆机制组成 Personalized Memory Feature

[Memory Slot](../concept-memory-slot/index.html) 区分用途；Summary 提供驻留概览；Application Policy 控制相关性；User Edit 提供纠正；[Past Chat Retrieval](../concept-past-chat-retrieval/index.html) 回到原始证据；Relationship Boundary 限制人设暗示。六者共同构成 [Personalized Memory Feature](../concept-personalized-memory-feature/index.html)。

权重 4.5：高权重复核中六个尾点均保护独立失败面，已全部拆分。来源：同章 §2-4，revision 227。

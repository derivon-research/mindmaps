# 多轮 ReAct

多轮 ReAct 是让同一 [ReAct Loop](../concept-react-loop/index.html) 连续转动多次，使后一轮行动可以依赖前一轮工具结果。轨迹长度、工具交错顺序与下一步查询内容都可在运行时由模型决定。

它适合事先不知道需要多少步的开放任务，但纯多轮 ReAct 容易“想到哪走到哪”，缺少覆盖多个维度的全局计划。

第七章用露营选择说明其与并行调用的差异：并行补一组互不依赖的事实，多轮调用则让“下一步查什么”依赖上一轮 Observation。

来源：《从 ReAct Loop 讲起》§3.3-4.4，revision 2846；《工具的真相》§6.3，revision 167。

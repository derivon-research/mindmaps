# 四类扩展点组成 Harness Plugin

[Prompt Fragment](../concept-prompt-fragment/index.html) 改变模型指令；Tool Definition Contract 扩展动作面；[Skill](../concept-skill/index.html) 按需提供任务方法；[Hook](../concept-hook/index.html) 拦截生命周期。四者联合成为 [Harness Plugin](../concept-harness-plugin/index.html)。

权重 4.0：高权重复核已拆分四个可独立装卸的扩展面，每项贡献不同。来源：同章 §7.1-7.2，revision 227。

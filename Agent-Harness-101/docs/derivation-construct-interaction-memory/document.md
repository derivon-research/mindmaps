# 构造 Interaction Memory

[组织 Ontology](../concept-organizational-ontology/index.html) 把对话识别为 Commitment、Objection 或 Assumption，[决策理由](../concept-decision-rationale/index.html)保存条件与权衡，[Dissenting View](../concept-dissenting-view/index.html) 保留异议，[Memory Permission](../concept-memory-permission/index.html) 保护敏感原文与角色边界。四者共同形成 [Interaction Memory](../concept-interaction-memory/index.html)。

权重 4.0：需要从 Transcript 跳到意义生成过程，同时不牺牲隐私。高权重复核：解释、理由、异议与权限已分别拆点。

来源：§2.2，revision 180。

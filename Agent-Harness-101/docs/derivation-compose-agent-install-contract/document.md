# 六个执行字段组成 Agent Install Contract

[Install Goal](../concept-install-goal/index.html) 定义目标；Success Criteria 定义完成；Operating Rules 限制副作用；Decision Tree 选择路径；TODO State 外置进度；[Setup Boundary](../concept-setup-boundary/index.html) 定义停止。六者共同组成 [Agent Install Contract](../concept-agent-install-contract/index.html)。

权重 4.5：高权重复核已把目标、验证、安全、分支、状态和停止分别拆点，每项解决独立失败面。来源：同章 §2，revision 118。

# 组装 Tool Definition 契约

[Tool Name](../concept-tool-name/index.html) 提供能力索引，[Tool 使用边界描述](../concept-tool-use-boundary-description/index.html)提供选择条件，[Tool Schema](../concept-tool-schema/index.html) 约束调用参数，[Tool Result 契约](../concept-tool-result-contract/index.html)保证下一轮能消费返回值。四者共同构成写给模型的 [Tool Definition 契约](../concept-tool-definition-contract/index.html)。

权重 3.0：四块分别决定识别、选择、填写和结果理解，任何一块缺失都会留下不同类型的不确定性。

来源：§2-3 与 §7，revision 167。

# 从恢复条件选择结果侧 Offloading

## 推导

[Tool Result](../concept-tool-result/index.html) 确定待治理的观察载体；[Offloading 候选资格](../concept-offloading-eligibility/index.html)排除小、热或不可恢复内容；[文件系统间接引用](../concept-filesystem-indirection/index.html)提供替换表示。三者共同得到[结果侧 Offloading](../concept-result-side-offloading/index.html)，并允许生成时快照与历史回收两种实现时机。

## 学习成本

权重 2.5：常规策略组合，难点在于资格而非结果体积本身。

# 从 Transcript 调优 Tool

[Tracing](../concept-tracing/index.html) 保存完整调用轨迹，[具体失败证据](../concept-specific-failure-evidence/index.html)定位未调用、误选、错参或回填噪音，[Evals](../concept-evals/index.html) 在固定问题集上回放改动。三者共同形成 [Transcript 驱动的 Tool 调优](../concept-transcript-driven-tool-tuning/index.html)。

权重 2.5：这是观测、诊断与回归的常规闭环，比凭感觉改 Description 更可辩护。

来源：§7.4，revision 167。

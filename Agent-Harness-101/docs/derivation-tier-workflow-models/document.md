# 按阶段边界分层使用模型

[Workflow 生成](../concept-workflow-generation/index.html)把低频结构设计交给强模型；[有边界的 Agent 阶段](../concept-bounded-agent-stage/index.html)允许普通模型执行清楚、可验收的高频工作；[模型分层](../concept-model-tiering/index.html)策略把少量困难节点重新分配给强模型。三者共同形成[成本感知 Workflow](../concept-cost-aware-workflow/index.html)。

权重 3.0：需要同时考虑设计时、执行时和例外节点，不能仅按价格统一降档。

来源：§7.2，revision 1503。

# 构造混合记忆检索

[Embedding Retrieval](../concept-embedding-retrieval/index.html) 召回未完全结构化材料，[Graph Expansion](../concept-graph-expansion/index.html) 补充 Owner、Commitment 和 Risk 等关系，Policy Layer 按角色裁剪可见内容。三者共同形成[混合记忆检索](../concept-hybrid-memory-retrieval/index.html)。

权重 3.0：覆盖、关系与权限缺一不可；只用向量或只用图都会漏掉不同材料。

# 从组织记忆协调行动

[Factual Memory](../concept-factual-memory/index.html) 提供当前事实与责任，[Interaction Memory](../concept-interaction-memory/index.html) 提供为何这样决定，Policy Layer 确定谁能知道和做什么，[Action Router](../concept-action-router/index.html) 把它们带回当前工作并选择推进、等待、求助、上报或停止。四者共同形成 [Action Memory](../concept-action-memory/index.html)。

权重 4.0：这是从记住到协调的主要桥梁。高权重复核：事实、解释、策略和路由均有独立职责，不是章节顺序边。

来源：§2.3 与 §3，revision 180。

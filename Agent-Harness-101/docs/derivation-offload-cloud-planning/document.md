# Planner 与独立 Agent 实现 Cloud Planning Offload

Planner Role 定义规划职责；[Sub-Agent](../concept-sub-agent/index.html) 提供独立执行边界；[Structured Output](../concept-structured-output/index.html) 约束返回计划。将该调用部署到云端更强模型，得到 [Cloud Planning Offload](../concept-cloud-planning-offload/index.html)。

权重 3.0：职责、隔离和计划契约缺一不可。来源：同章 §4“创新六”，revision 174；状态：未发布观察。

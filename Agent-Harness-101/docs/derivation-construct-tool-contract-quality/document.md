# 构造高质量 Tool 契约

[动作式 Tool 命名](../concept-action-oriented-tool-name/index.html)提高可识别性，使用边界描述明确何时用与不用，[收窄参数 Schema](../concept-narrow-parameter-schema/index.html) 降低填写自由度，[Tool Result 契约](../concept-tool-result-contract/index.html)服务下一轮推理，[非重叠 Tool 职责](../concept-nonoverlapping-tool-responsibility/index.html)减少选择摇摆。五者共同建立 [Tool 契约质量](../concept-tool-contract-quality/index.html)。

权重 4.0：这是章节工程调优的主要综合单元。高权重复核：名字、选择边界、参数、结果和工具间职责均已拆点，分别约束不同失败面。

# 目标、发现、计划、执行与验证构成循环周期

[人类目标所有权](../concept-human-goal-ownership/index.html)给出方向；Discovery 找出当前缺口；[Plan-then-Act](../concept-plan-then-act/index.html) 组织步骤；Execute 产生改变；Verify 根据标准决定交付或迭代；[跨会话记忆](../concept-cross-session-memory/index.html)保存每轮进度。合起来得到可接续的目标驱动循环周期。

权重 4.0：需要把六个生命周期角色放到正确顺序并理解失败回边。高权重复核：所有阶段和 Memory 都是独立点，未把可复用中间步骤藏在大边里。

来源：同章 §3 与 §5，revision 1389。

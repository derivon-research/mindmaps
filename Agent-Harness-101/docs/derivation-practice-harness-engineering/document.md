# 把 Harness、Tracing 与 Evals 组织成工程实践

[Agent Harness](../concept-agent-harness/index.html) 提供可修改的工程对象；[Tracing](../concept-tracing/index.html) 提供运行证据；[Evals](../concept-evals/index.html) 判断改动是否改善。把对象、证据和验收连起来，Harness 才能作为独立制品持续迭代，而不只是零散“调配置”。

权重 3.0：需要建立工程对象到观测、评测、迭代的完整工作环，但各中间概念已独立建点。

来源：同章 §1-4；与第 1 章 [Self-evolving Harness](../concept-self-evolving-harness/index.html) 证据相互补充。

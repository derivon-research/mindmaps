# Acceptance Criteria

Acceptance Criteria 是事先约定、客观可判定的完成条件，用来回答任务是否达标。

研发案例把目标写成三项：指定 acceptance tests 全绿、typecheck 无报错、现有测试无新增失败。它比“把测试补好”更能驱动闭环收敛。

# Workflow 生成

Workflow 生成由旗舰模型根据当前任务一次性产出 [Workflow Script](../concept-workflow-script/index.html)，而不是要求工程师预先手写固定 pipeline。

这一步是 [Dynamic Workflow](../concept-dynamic-workflow/index.html) 中“Dynamic”的来源。生成成本只发生一次，随后可由普通模型支撑多次执行；来源中的 DeerFlow 3.0 `workflow-creator` 仍是计划形式，不是已定稿接口。

# 沿 Trust Curve 放开行动

[Action Router](../concept-action-router/index.html) 从低风险建议开始，[Trust Curve](../concept-trust-curve/index.html) 用组织经验逐步积累信任，[Human-in-the-loop](../concept-human-in-the-loop/index.html) 在关键阶段保留确认。三者共同形成[渐进式行动自动化](../concept-graduated-action-automation/index.html)。

权重 2.5：需要同时控制动作范围、信任进度和人工责任，不能仅以技术可执行性决定自动化程度。

来源：§3，revision 180。

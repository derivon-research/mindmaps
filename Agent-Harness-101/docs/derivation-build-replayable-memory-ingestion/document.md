# 构造可回放记忆摄取

[Append-only Event Log](../concept-append-only-event-log/index.html) 保存原始材料，[Extracted Claim](../concept-extracted-claim/index.html) 把 LLM 输出降格为候选断言，[Claim Lifecycle](../concept-claim-lifecycle/index.html) 允许后续确认、推翻或升级。三者共同让记忆摄取可纠错、可重放。

权重 3.0：需要把原始证据与可变解释分离，三个尾点分别提供回放、候选和演化。

来源：§3，revision 180。

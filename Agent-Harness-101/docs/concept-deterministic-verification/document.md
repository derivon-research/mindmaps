# 确定性验证

确定性验证把 [Acceptance Criteria](../concept-acceptance-criteria/index.html) 映射为机器可执行的检查，并用通过/失败结果控制循环是否继续。

它把“我觉得做完了”替换成可重复的外部判定，是 [Closed Loop](../concept-closed-loop/index.html) 成本和终态可控的关键。

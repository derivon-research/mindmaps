# 人工审核闸门

人工审核闸门让 Agent 先收集信息并产出草稿，再由人决定是否发送、发布或执行高影响动作。

它保留自动化的信息处理收益，同时防止不确定判断直接变成不可逆外部行为。

[Company Brain](../concept-company-brain/index.html) 将该闸门放进组织 [Trust Curve](../concept-trust-curve/index.html)：先生成 Briefing、建议 Ticket 或请求确认，再在证据、权限和使用经验成熟后逐步授权半自动或自动执行。

来源：《从零认识 [Loop Engineering](../concept-loop-engineering/index.html)》§7，revision 1389；《Company Brain》§3，revision 180。

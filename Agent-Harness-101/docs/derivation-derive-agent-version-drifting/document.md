# 从历史 Few-shot 解释 Version Drifting

[历史行为轨迹](../concept-historical-behavior-trace/index.html)提供旧调用的具体范本，[隐式 Few-shot](../concept-implicit-few-shot/index.html) 说明模型可能把它当作当前示例，[破坏性契约变更](../concept-breaking-contract-change/index.html)则让该范本与当前定义冲突。三者共同形成 [Agent Version Drifting](../concept-agent-version-drifting/index.html) 的工程解释。

权重 3.0：需要同时理解历史示例性和契约冲突。该边记录有来源支持但尚需系统评测的解释，不宣称单次实验已经证明因果。

来源：§1-3，revision 270。

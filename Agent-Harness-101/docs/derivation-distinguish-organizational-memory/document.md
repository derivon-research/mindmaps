# 从相关文本走向组织记忆

[Retrieval 相关性](../concept-retrieval-relevance/index.html)找到可能有关的文字，[组织语义](../concept-organizational-meaning/index.html)解释该信息对角色、时间、风险和当前决策意味着什么。两者结合才形成能回到决策现场的 [Organizational Memory](../concept-organizational-memory/index.html)。

权重 2.5：需要跨越“找到”与“理解其组织意义”的关键区别，二者不可互换。

来源：§1，revision 180。

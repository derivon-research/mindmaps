# 构造 Factual Memory

[Provenance](../concept-provenance/index.html) 绑定证据，[Memory Owner](../concept-memory-owner/index.html) 绑定责任，Timestamp 给出时间边界，Permission 控制可见与可行动范围，Freshness 标记是否过期，Confidence 表示抽取确定度，[Context Graph](../concept-context-graph/index.html) 连接客户、项目、承诺和风险。七者共同构成可审计的 [Factual Memory](../concept-factual-memory/index.html)。

权重 4.5：字段多但每项保护独立失败面。高权重复核：来源、责任、时间、权限、时效、置信与关系均已拆点，不把 YAML 样式本身误建为知识。

来源：§2.1，revision 180。

# 周期、事件与持久状态组成 Autonomous Daemon Agent

Recurring [Agent Loop](../concept-agent-loop/index.html) 提供周期运行；事件驱动 Trigger 提供外部唤醒；Cross-Session Memory 保持连续性；[Memory Consolidation](../concept-memory-consolidation/index.html) 整理长期观察。四者共同构成 [Autonomous Daemon Agent](../concept-autonomous-daemon-agent/index.html) 的来源设想。

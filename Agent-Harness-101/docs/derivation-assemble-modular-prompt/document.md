# 可寻址 Fragment 组成模块化 Prompt

[Prompt Fragment](../concept-prompt-fragment/index.html) 提供零件；[Prompt 模块可寻址性](../concept-prompt-module-addressability/index.html)支持替换和排序；[System Prompt](../concept-system-prompt/index.html) 承载最终装配结果。三者共同建立[模块化 Prompt 装配](../concept-modular-prompt-assembly/index.html)。

权重 3.0：需要区分源模块与渲染后的单条消息。来源：同章 §6，revision 227。

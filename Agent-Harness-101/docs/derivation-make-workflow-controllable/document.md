# 让 Workflow 可控

[Workflow 可观测性](../concept-workflow-observability/index.html)让人看见进度，[Workflow 人工介入](../concept-workflow-intervention/index.html)让人插得上手。二者联合使用户能在错误扩大前理解状态并采取动作，形成[可控 Workflow](../concept-controllable-workflow/index.html)。

权重 2.0：这是来源明确给出的“看得见又插得上”组合；只有可见但不可介入，或能介入却不知状态，都不充分。

来源：§6，revision 927。

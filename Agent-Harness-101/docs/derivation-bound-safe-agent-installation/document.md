# 规则、权限与密钥边界约束 Agent 安装

[Install Operating Rules](../concept-install-operating-rules/index.html) 规定项目边界；[Tool Permission Gate](../concept-tool-permission-gate/index.html) 控制高影响动作；[Secret Non-Inspection](../concept-secret-noninspection/index.html) 保护凭据；[Setup Boundary](../concept-setup-boundary/index.html) 阻止安装后继续扩张。四者共同约束安全安装。

权重 3.5：四个尾点分别保护文件、执行授权、机密和任务范围。来源：同章 §2.3-2.7，revision 118。

# Foundation Model 与 Harness 构成 Agent 系统

[Foundation Model](../concept-foundation-model/index.html) 提供推理和生成能力；[Agent Harness](../concept-agent-harness/index.html) 提供指令、工具循环、运行环境、上下文、权限和调度。两者共同决定用户实际接触的 [Agent 系统](../concept-agent-system/index.html)，正对应来源公式 `agent = models + harness`。

权重 2.0：是清晰的两部分组合，但读者需区分能力上限与工程实现两个责任面。

来源：《Harness 101：模型之外的全部》revision 297，§1-2 与 §9。

# 亚 1 V 带隙基准

传统带隙输出约 1.2 V，不能直接由低于该值的电源提供。低压方案不在电压域直接相加，而把 `VBE/R` 与 `Delta VBE/R` 转成电流，汇流后再由输出电阻缩放成约 0.5-0.6 V。

所利用的物理量仍是硅带隙关系；降低的是输出缩放和供电堆叠，不是创造新的低电压常数。最低供电至少要容纳一个低电流 `VBE` 加必要饱和裕量。

来源：第 16 章 pp. 474-477，1636-1642。

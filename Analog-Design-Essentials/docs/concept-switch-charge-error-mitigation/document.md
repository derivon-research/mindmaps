# 开关电荷误差抑制

开关误差可用三条独立路线减弱：互补传输门让 nMOST 与 pMOST 的时钟馈通和沟道电荷部分抵消；反相驱动的伪开关吸收主开关释放的电荷；全差分信号通路把对称注入变成可拒绝的共模量。

补偿依赖器件、电容与时钟边沿匹配。伪开关尺寸尤其取决于两端阻抗：快边沿且两端电容相近时常取半尺寸，慢边沿或不对称负载下可能需要不同尺寸，选错反而恶化误差。

来源：第 17 章 pp. 496-498，图 17.24-17.26。

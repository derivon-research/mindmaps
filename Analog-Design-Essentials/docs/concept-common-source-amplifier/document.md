# 共源单管放大器

共源级把栅端小信号电压经 `gm` 转成漏端电流，并由输出电阻转换成反相电压。理想电流源负载在小信号下开路，因此低频增益为 `Av0=-gm*rDS`，其大小就是 MOST 本征增益。

高增益设计选小 `VOV`、长 `L`；深亚微米最小沟道单管增益很低，必须用级联管或增益提升。源书的 100 MHz、3 pF 例题以 `gm=2*pi*GBW*CL` 求跨导，再按 `VOV=0.2 V` 求电流与尺寸，示范从动态规格反推器件。

来源：第 2 章 pp. 51-55，021-029。

# 在共同指标下比较轨到轨输入路线

各拓扑点分别给出强反型分流、弱反型反馈、内部电源、单对升压、差分电流选择和电阻移位的工作机制；FOM 统一动态功耗口径，失调过渡与信号路径噪声则补上表中不能由 FOM 代表的质量维度。把这些结果放入同一指标矩阵，才能按供电、失真、噪声与效率约束排除不合适路线。

来源：第 11 章 pp. 307-335，1113-1168。边权 4：比较结论要求联合多个不可互换的架构与指标，而各机制和风险均已独立建点；剩余工作是不可再分的多指标架构判断。

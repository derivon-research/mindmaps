# 源跟随参考 Class-AB 跨导器

源跟随参考跨导器让一只恒流源跟随器把第二输入电压无衰减地送到主输入管源极，主输入管栅极接第一输入。主管因此单独完成差分电压到电流的转换。

主管交流电流不受固定尾电流限制，并因 MOST 平方律呈扩张型；电流镜把它送往单端或全差分输出。结构只需约 `VGS+VDSsat` 余量，低阈值实例可在约 0.6-0.7 V 工作。

来源：第 12 章 pp. 358-361，1243-1247。

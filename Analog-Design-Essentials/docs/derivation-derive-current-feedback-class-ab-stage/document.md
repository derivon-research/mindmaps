# 以附加镜像反馈解除差分对尾电流限制

普通差分对把固定尾电流在两支间转向，输出必然限幅；电流镜和差分电流放大器可把一支输出复制回另一支输入路径。加入这条正向电流反馈后，两条贯穿电源的环流由器件尺寸和输入共同决定，不再由 `Ibias` 封顶，因而形成扩张型输出。

来源：第 12 章 pp. 354-355，1234-1236。边权 4：只增加一管却改变整个电流闭合关系，必须联合追踪差分转向、镜像极性、环流和互补方向；这是不可再拆的拓扑重构。

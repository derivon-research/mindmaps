# 单级 OTA 功耗品质因数

单级 OTA 的功耗效率可用 `FOM = GBW*C_L/I_total` 衡量，常用单位为 `MHz*pF/mA`。由于 `GBW=g_m/(2pi C_L)`，该指标实质上比较单位电流能提供多少跨导。

书中的差分单级 CMOS OTA 约可达到 800–1000 `MHz*pF/mA`，为后续多级拓扑提供功耗基准；加入噪声或摆幅后可扩展成更完整的 FOM。

来源：第 6 章 pp. 181-183，063-064。

# 高速 Miller OTA 尺寸流程

先选负载/补偿、补偿/内部电容及非主极点/GBW 三个比例，再由目标 GBW 求最低 `f_T6`。据此选择工艺、`L6` 与过驱动或反型系数；`C_L` 决定 `W6` 和输出电流，随后得到 `C_n1,C_c,g_m1` 与输入级尺寸。

沟道可适度加长以换取增益或调整反型程度，但必须重新验证 `f_T`、电流和 FOM。

来源：第 6 章 pp. 193-196，0624-0629。

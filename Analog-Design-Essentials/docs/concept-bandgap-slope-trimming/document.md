# 带隙基准斜率修调

实际 `VBE`、面积比和电阻比都有工艺误差，未经修调的 PTAT 增益不能精确抵消 CTAT 斜率。调节电阻比或镜像比例，使 `dVref/dT` 在参考温度 `Tr` 处为零，即完成一次斜率修调。

从几何上看，修调让残余曲率在目标温区关于 `Tr` 尽量对称。它主要消除 PTAT 型增益误差，不会自动消除二阶曲率，因此高精度基准常需要第二次曲率修调。

来源：第 16 章 pp. 460-461、467，168、1621-1622。

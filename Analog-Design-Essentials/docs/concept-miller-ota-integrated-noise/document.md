# Miller OTA 积分噪声

单位反馈下，输入级白噪声谱随一阶闭环带宽积分，噪声带宽为 `(pi/2)GBW`。输入噪声中的 `1/g_m1` 与 `GBW=g_m1/(2pi C_c)` 相消，使总积分噪声主要按 `kT/C_c` 缩放。

因此两级或三级补偿 OTA 的积分噪声由主补偿电容主导；增大 `C_c` 可降噪，却要求更大跨导和电流维持 GBW。书中例子里第二级仍贡献约 20%，不能在精确验证中永久忽略。

来源：第 6 章 pp. 206-208，0648-0651。

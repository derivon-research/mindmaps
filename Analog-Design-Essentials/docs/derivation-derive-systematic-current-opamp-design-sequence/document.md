# 按跨阻、偏置、反馈模式和噪声排序设计

跨阻带宽积先给出小信号可达范围，噪声速度折衷确定偏置，固定 `R_S` 或 `R_F` 的选择决定闭环曲线，有限输入电阻再裁剪高增益区域。若增加第二级，输入 cascode 噪声判据必须在补偿电容的高频极限下重算。

来源：第 10 章 pp. 291-300，101-1020。边权 4：这是把量纲正确的性能界限、大信号偏置、两种反馈模式、器件输入电阻和多级噪声验证组织成可回退流程；中间结论均已独立建模。

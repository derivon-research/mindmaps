# 基准电压-电流转换

运放反馈把 `Vref` 精确施加到电阻 `R` 上，得到 `Iref=Vref/R`，再由输出管或电流镜送往负载。主要 DC 误差来自运放失调、基准误差和电阻绝对值误差。

温度系数由 `Vref` 与 `R` 的温漂之差决定，可有意选择两者互补。与电压基准不同，电流基准必须依赖某种阻性或时钟电容尺度，因此其绝对精度通常更差。

来源：第 16 章 pp. 458、478-479，163、1643-1646。

# 双极型电容模型

双极型器件的输入电容 `Cpi` 由正偏基射结电容 `CjBE` 和扩散电容 `CD` 组成。基区内储存电荷约为 `QB = tauF*IC`，因此

`CD = dQB/dVBE = tauF*gm`。

低电流时结电容占主导，高电流时扩散电容占主导。反偏的集基电容 `Cmu` 和集电极-衬底电容 `CCS` 随结电压变化；后者面积大且常接在输出端，对高频性能尤其重要。

来源：第 1 章，书页 41-43，幻灯片 0177-0179。

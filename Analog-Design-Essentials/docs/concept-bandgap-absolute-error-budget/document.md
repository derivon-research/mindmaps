# 带隙基准绝对误差预算

源书对运放式 CMOS 带隙基准做全微分，`VBE` 项和放大 `Delta VBE` 项的工艺误差合计约 24 mV，即约 2%。这些误差主要表现为 PTAT 增益偏差，可通过调节增益系数 `A` 修掉。

未计入的运放失调等效为两只双极管的额外 `Delta VBE`，会直接污染输出。因而一次修调前，失配和失调通常大于本征曲率；斩波放大器可降低失调贡献。

来源：第 16 章 p. 467，1621-1622。

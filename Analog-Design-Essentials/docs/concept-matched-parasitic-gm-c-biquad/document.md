# 寄生匹配 Gm-C 双二阶单元

极高频 Gm-C 双二阶可不加显式电容，直接把节点所有输入、输出寄生之和作为状态电容 C。为让两个差分状态节点看到相同寄生，加入哑跨导块，使每个节点连接相同数量、同类型的跨导输入与输出端。

这样可把不可避免的寄生转成匹配元件并提高寄生极点，但 `gm2*` 仍必须包含输出电导。源书 50 MHz 示例用跨导比参数调 Q、用时间常数调 `f0`。

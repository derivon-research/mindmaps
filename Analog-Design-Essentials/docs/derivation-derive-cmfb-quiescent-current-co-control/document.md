# 复用共模输出电压设定功率管静态电流

CMFB 控制全差分前级的平均输出；Class-AB 输出管的静态电流由两栅平均电压形成的 `VGS` 决定；跨线性环又能把这些 `VGS` 约束为目标电流。让共模感知晶体管同时进入跨线性环，同一反馈量便同时设定前级共模和末级 `IQ`。

来源：第 12 章 pp. 351-352，1229-1230。边权 4：这是两个控制目标共享传感器、执行节点和器件环的系统级合并；各子环已显式建点，协同连接不可再拆。

# 反馈闭环非线性系数

对开环非线性 `y=a1*u+a2*u^2+a3*u^3+...` 施加反馈因子 `F`，令 `T=a1*F`，闭环仍可写成系数为 `d1,d2,d3,...` 的幂级数。`d1` 按 `1+T` 降低；大环路增益下，`d2` 约按 `(1+T)^3` 降低。

`d3` 的分母约为 `(1+T)^5`，但分子同时含原始 `a3` 和由 `a2` 再循环形成的项，二者符号可能相反。闭环三阶失真因此不能只把开环 `a3` 除以一个增益因子。

来源：第 18 章 pp. 542-544，图 18.47-18.50。

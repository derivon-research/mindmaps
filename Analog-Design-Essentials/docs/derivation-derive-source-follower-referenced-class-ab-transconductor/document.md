# 以跟随源端构造单管扩张跨导

恒流源跟随器把 `Vin2` 复制到主管源极，主管栅极接 `Vin1`，于是主管 `VGS` 等于差分输入。强反型平方律使其漏电流随差分过驱动扩张，差分电流放大器再以低压镜像输出；固定偏置只负责跟随器，不限制主信号电流。

来源：第 12 章 pp. 358-361，1243-1247。边权 4：这是把普通差分对拆成“恒流跟随参考”和“单管无限幅跨导”的关键低压重构；各器件功能已由尾点承载，连接关系不可再拆。

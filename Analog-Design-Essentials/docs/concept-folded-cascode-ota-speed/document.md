# 折叠级联 OTA 的速度

折叠级联 OTA 的输出是唯一高阻节点，因此仍属单级 OTA：

[
GBW=rac{g_{m1}}{2pi C_L}.
]

节点 1、2 在差分模下只形成一个非主极点，近似为
(f_{nd}=g_{m3}/(2pi C_{n1})approx f_{T,n1}/3)；其他上侧节点多形成展宽比约 2 的极零双点。因此它可以很快，但相同输入支路条件下约消耗伸缩式级联的两倍电流。

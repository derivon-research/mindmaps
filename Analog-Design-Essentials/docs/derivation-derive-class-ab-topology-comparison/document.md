# 在共同约束下比较 Class-AB 路线

各架构点分别给出扩张电流、反相器电源抑制限制、静态偏置、交越保护、局部线性化、低压补偿和少器件信号路径；驱动能力与推挽余量提供共同的输出指标。把这些机制放入同一约束矩阵，才能判断某方案是以失配、极点、供电、噪声还是复杂度换取峰值电流与低失真。

来源：第 12 章 pp. 337-361，121-1248。边权 4：比较需要联合不可互换的架构和指标，而每个机制已独立建点；剩余多指标判断是不可再拆的架构决策。

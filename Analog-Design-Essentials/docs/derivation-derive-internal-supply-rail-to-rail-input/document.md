# 以双反馈维持自动精确交越

精确交越给出最低电源与恒定总跨导的目标；复制 CMFB 让两输入对电流相等，复制 LDO 又让内部电源等于两套半跨导支路的实时余量。两环分别控制“电流相等”和“电压刚够”，共同消除绝对 `V_T` 对固定电源设定的依赖，形成可由约 1.3 V 外部电源工作的输入级。

来源：第 11 章 pp. 322-327，1143-1152。边权 4：双环分别调节不同状态量，只有联合闭合才建立自动精确交越；两个子环和交越目标都已显式建点，整体集成是不可省略的系统级步骤。

# 双极型小信号模型

对指数电流求导得到 `gm = IC/UT`，所以 `gm/IC = 1/UT ~= 40 V^-1`。输出电阻用 Early 电压表示为 `ro ~= VE/IC`；基极输入电阻为 `rpi = beta/gm`，另有工艺与版图决定的串联基极电阻 `rB`。

`VE` 与有效基宽有关，但垂直 npn 中不是设计者自由度。`beta` 的不确定性使 `rpi` 不适合承担精密比例功能。这个模型把双极器件的高跨导效率、有限输入电流和有限输出电阻同时暴露出来。

来源：第 1 章，书页 41，幻灯片 0176。

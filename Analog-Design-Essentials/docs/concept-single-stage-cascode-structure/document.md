# 单级级联管的节点结构

cascode 是一个只有一个主要高阻增益节点的单级放大器；cascade 是两个完整放大级串接，存在两个高阻节点和两个显著极点。两者低频增益可相近，但动态、功耗和稳定性问题不同。

单级 cascode 的 GBW 由输入跨导和输出负载电容决定。两级 cascade 常需在第二级跨接补偿电容，使 GBW 改由输入跨导和补偿电容决定，并增加功耗与稳定性设计负担；它可能换来更大的输出摆幅。

来源：第 2 章 pp. 81-82，0260-0261。

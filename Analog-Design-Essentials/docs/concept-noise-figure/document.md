# 噪声系数

噪声系数 `F` 是包含放大器附加噪声后的总输入噪声功率与源阻 `R_S` 自身热噪声功率之比。对不相关的输入电压噪声 `e_n` 和电流噪声 `i_n`，可写成 `F = 1 + (e_n^2 + i_n^2 R_S^2)/(4kTR_S)`。

小 `R_S` 时电压噪声主导，大 `R_S` 时电流噪声主导。MOST 近似没有栅输入电流噪声，而 BJT 的基极散粒噪声会限制高源阻性能。

来源：第 4 章 pp. 132-133，0430-0431。

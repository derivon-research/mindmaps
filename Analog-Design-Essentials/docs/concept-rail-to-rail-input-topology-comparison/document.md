# 轨到轨输入拓扑比较

轨到轨输入方案应至少同时比较四类指标：总跨导误差、`GBW*C_L/I_total`、最低供电，以及未被 FOM 包含的失调过渡失真、输入噪声和偏置电流。

三倍镜与电子齐纳适合较高电源的强反型均衡；复制 CMFB 与内部电源方案以弱反型和反馈换取 1.5-1.3 V；升压单对输入以额外电源域换取约 90 dB 低失真；最大电流选择方案牺牲噪声；电阻移位能在常规阈值下达到 1 V，却付出噪声和输入电流代价。不存在只凭最低电压或 `g_m` 误差即可选出的普遍最优项。

来源：第 11 章 pp. 307-335，1113-1168。

# 衬底 pnp 带隙基准

n 阱 CMOS 中的垂直衬底 pnp 以 p+ 扩散为发射极、n 阱为基极、公共 p 衬底为集电极。所有集电极天然相连并通常接地，但其 beta 尚可、输出电阻高，指数区比横向寄生双极管更实用。

利用衬底 pnp 的 `VBE` 和面积比 `Delta VBE`，CMOS 工艺可复用双极带隙原理。拓扑必须接受公共集电极约束，并为 CMOS 运放的更大失调与 1/f 噪声留出面积和修调预算。

来源：第 16 章 pp. 470-472，1627-1630。

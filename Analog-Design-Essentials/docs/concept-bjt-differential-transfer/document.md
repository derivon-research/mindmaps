# 双极型差分对大信号传输

指数电流与尾电流守恒给出 `iod=IB*tanh[vid/(2UT)]`。零点斜率是 `IB/(2UT)=gm`；当输入约为 `6UT`（约 0.14 V）时，输出电流已接近最终值 1% 以内。

双极对的 `UT` 固定了高跨导和窄输入范围，不能像 MOST 那样用 `VOV` 独立调整。加入发射极退化电阻可扩大范围，但按反馈比例降低小信号跨导。

来源：第 3 章 pp. 100-102，0323、0325-0326。

# 非线性泰勒系数

在静态工作点令小信号输入为 `u=0`，平滑传输曲线可写为

`y = a0 + a1*u + a2*u^2 + a3*u^3 + ...`，

其中 `a_n = (1/n!)*(d^n y/du^n)|_(u=0)`。`a0` 是静态输出，`a1` 是小信号增益，`a2`、`a3` 分别代表主要偶次与奇次非线性。模型在工作区交界处必须具有足够阶的连续导数，否则不能可靠地提取相应系数。

来源：第 18 章 pp. 522-523，图 18.8-18.9。

# 三阶截点 IP3

在弱失真区，把基波的 1 dB/dB 直线与三阶互调产物的 3 dB/dB 直线外推，其交点输入幅度称为输入三阶截点：

`IP3 = sqrt((4/3)*(a1/a3)) = Vin/sqrt(IM3)`。

用 dB 表示时，`IP3_dB = Vin_dB - (1/2)*IM3_dB`。它是外推指标，实际电路通常会在到达交点前压缩或削顶。

来源：第 18 章 pp. 528-529，图 18.21-18.23。

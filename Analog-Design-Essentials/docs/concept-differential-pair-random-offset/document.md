# 差分对随机失调

电阻负载 MOST 差分对的一阶输入失调为

`vos = Delta VT + (VOV/2)*(Delta RL/RL + Delta K'/K' + Delta(W/L)/(W/L))`。

四项按代数符号叠加，不应把所有绝对值相加成不现实的最坏情况，也不能假定完全抵消。除 `Delta VT` 外的各项都乘以 `VOV/2`；减小过驱动或进入弱反型可降低这些贡献，但 MOST 的失调修调点会随偏置、供电和温度漂移。

来源：第 15 章 pp. 426-427，1511-1512。

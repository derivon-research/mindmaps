# 通过跨导缓冲回送第二补偿电容

用 `g_mt` 的低输入阻抗隔离第二级，再让 `Cm2` 经该跨导反馈，可避免电容直接分流放大节点。选择 `k_t>1` 排列高阶极点，利用重复零点抵消一个非主极点，并把剩余左半平面零点放在主要极点稍上方；前馈支路同时完成 Class-AB 驱动。

来源：第 9 章 pp. 285-287，0945-0948。边权 4：需联合跨导缓冲、可控跨导比、四极点三零点配置和大信号前馈，是本章功耗改善最大的完整补偿构造。

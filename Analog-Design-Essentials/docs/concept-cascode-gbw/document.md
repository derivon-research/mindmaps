# 级联放大器 GBW 守恒

当输出 `CL` 是主导电容且负载为高阻电流源时，cascode 提高 `Rout`，因而低频增益按同一比例提高、带宽按同一比例下降；两者乘积仍为输入管的 `gm/(2*pi*CL)`。

所以普通 cascode 主要增强低频增益，不提高该条件下的 GBW。若外部负载本来很低（如 50 ohm），两种结构都由负载决定，增益和 GBW 也都很小。

来源：第 2 章 pp. 78-79，0254-0255。

# 消去器件尺寸得到失配工艺约束

阈值面积律把精度写成 `WL`、`VOV` 和 `AVT` 的函数；`fT` 关系把速度写成电流、`WL`、`Cox` 和 `VOV` 的函数。用功耗与偏置电流成正比消去 `WL` 和电流后，留下 `Speed*Accuracy^2/Power ~= 1/(Cox*AVT^2)`。

来源：第 15 章 p. 453，1564。边权 4：跨越失配统计、器件速度和偏置功耗三套关系完成变量消元并解释工艺常数。

# 失配限制的速度-精度-功耗约束

若精度主要由阈值失配限制，则 `1/Accuracy^2 ~= 4*AVT^2/[WL*VOV^2]`；再用 `fT` 的面积、电流关系消去尺寸，可得

`Speed*Accuracy^2/Power ~= 1/(Cox*AVT^2) ~= 1/tox`。

在给定 CMOS 工艺内，速度、精度和功耗不能独立任意提高；右端近似是工艺常数。缩小氧化层可能改善该比值，但实际设计仍受几何失配和供电缩放限制。

来源：第 15 章 p. 453，1564。

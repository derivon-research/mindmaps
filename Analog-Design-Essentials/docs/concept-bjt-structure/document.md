# 双极型晶体管结构

双极型晶体管由相邻的发射结和集电结构成：发射结正偏向薄基区注入少数载流子，集电结反偏收集大部分载流子。垂直 npn 的基区宽度由扩散深度差决定；横向 pnp 的有效基宽由横向间距决定，通常电流增益较低。

集电区常带埋层以降低串联电阻，基区也可能增加接触扩散。与 MOST 的横向沟道不同，垂直双极器件的基宽通常由工艺固定，而不是每个晶体管可自由选择的版图参数。

来源：第 1 章，书页 39-40，幻灯片 0173-0174。

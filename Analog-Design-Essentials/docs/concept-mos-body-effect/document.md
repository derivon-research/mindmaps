# MOST 体效应

体源结的反向偏置增大时，沟道下耗尽层变宽，建立反型所需的栅压增加，所以阈值电压的绝对值上升。源书采用常见的平方根修正：

`VT = VT0 + gamma[sqrt(2phiF + VSB) - sqrt(2phiF)]`。

`gamma` 由衬底掺杂和氧化层等工艺量决定；体偏本身则是电路工作点的一部分。开关或源跟随器中若源端随信号移动，不能把 `VT` 当作固定值。

来源：第 1 章，书页 10-11，幻灯片 0118-0119。

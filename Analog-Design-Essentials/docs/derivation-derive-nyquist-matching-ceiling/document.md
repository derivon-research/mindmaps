# 从元件匹配推出 Nyquist ADC 实用精度上限

电阻、电容、比较器和电流源的随机失配都需压到最终 LSB 内；位数每增加一位，允许误差约减半而器件面积快速上升。源书据此把常规 Nyquist ADC 的实用匹配上限放在约 12-14 位。

来源：第 20 章 pp. 609、614、620、630、635，图 20.15、20.22、20.35、20.53、20.62。边权 3：跨多种架构统一比较 LSB 误差预算与面积缩放。

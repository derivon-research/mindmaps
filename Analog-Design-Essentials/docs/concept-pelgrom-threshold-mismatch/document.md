# 阈值电压失配面积律

邻近匹配 MOST 的阈值电压标准差近似满足

`sigma(Delta VT) = AVT/sqrt(WL)`。

`AVT` 是工艺相关系数，面积 `WL` 才是随机项的一阶控制量；把 `W`、`L` 同时放大两倍会使标准差减半。源书时代的经验是 `AVT` 的数值与栅氧厚度相关，但 130 nm 以下可能趋于约 `3 mV*um`，外推必须谨慎。

来源：第 15 章 pp. 423-425，156-158。

# 两级运放稳定性尺寸关系

联立 `GBW=g_m1/(2pi C_c)` 与 `f_nd≈g_m2/(2pi C_L)`，再施加 `f_nd≈3GBW` 和内部电容修正，可得到 `g_m2/g_m1` 与 `C_L/C_c` 的比例约束。

若 `C_c` 取 `C_L` 的 1/2–1/3，在相同过驱动下第二级电流常需达到单个输入管的约 8–12 倍。负载增大时，必须增大 `C_c` 或 `g_m2`。

来源：第 5 章 pp. 165-166，0531-0533。

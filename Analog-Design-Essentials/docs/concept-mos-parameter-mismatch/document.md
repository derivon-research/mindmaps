# MOST 参数失配模型

MOST 随机失配不只来自 `Delta VT`。工艺跨导因子满足 `Delta K'/K' = AK'/sqrt(WL)`；几何比误差可写成 `Delta(W/L)/(W/L) = AWL*sqrt(1/W^2+1/L^2)`，因此较小的几何尺寸主导；体效应参数也有面积律。

输入 pMOST 可共用同一 n 阱并把体端接源端，从而抑制体效应参数散布。源书数据还指出 `AVT` 随工艺缩放下降，而 `AWL` 约停在 `2%*um`，因此未来几何误差可能转为主导项。

来源：第 15 章 pp. 425-426，159-1510。

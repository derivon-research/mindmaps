# 串并联电压放大器

非反相电压放大器把输出电压经 `R1,R2` 分压后串联比较于输入，闭环增益 `Av=(R1+R2)/R1`。环路增益 `T=A0*R1/(R1+R2)=A0/Av`，因此高 `A0` 时闭环增益主要由电阻比确定。

有限开环端口阻抗下，`Rin=Rin,OL*(1+T)`，`Rout=Rout,OL/(1+T)`；书中高环路增益近似把 `1+T` 写作 `T`。该拓扑趋近理想电压控制电压源。

来源：第 13 章 pp. 368-374，1310-1322。

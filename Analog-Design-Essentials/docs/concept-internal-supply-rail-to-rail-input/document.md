# 内部电源轨到轨输入

内部电源轨到轨输入结构以外部电源供电，却为输入级生成更低且受控的内部电源。电流相等环使两种输入对在交越处具有相等跨导，复制 LDO 则把内部电源保持在精确交越所需的最低值。

书中实测内部电源约 1.2-1.3 V，外部电源最低约 1.3 V，`g_m`/GBW 变化约 6%，FOM 约 56 `MHz*pF/mA`。复制级数量增加面积，弱反型输入噪声也较高；折叠支路还限制最高外部电源约 1.8 V。

来源：第 11 章 pp. 322-327，1143-1152。

# 串联电阻的电流源降噪

在电流源器件源极或发射极串入电阻后，局部反馈以约 `(g_mR)^2` 抑制晶体管噪声功率。当 `g_mR > 1` 时，电阻自身的并联电流噪声 `4kT/R` 成为主导，并随 `R` 增大而下降。

对 MOST，直接选用较大过驱动、较小 `W/L` 可得到与源退化相近的增益和噪声效果；复杂的分流加电阻方案若没有额外电压余量，并不会带来净收益。

来源：第 4 章 pp. 138-141，0443-0447。

# 光电二极管电流源模型

受光光电二极管在接收器输入端可建模为信号电流源与结电容 `CD` 并联。输入晶体管的 `CGS` 和互连寄生再并入总输入电容 `CP=CD+CGS+...`；经过电容噪声匹配后常有 `CGS~=CD`，故一阶估算可取 `CP~=2CD`。

信号量是电流而非开路电压，因此前端必须提供低而可控的输入阻抗，避免 `CP` 把带宽压低。

来源：第 14 章 pp. 396、408-410，1416、1439-1443。

# 差分对系统性失调

有源负载差分对即使没有随机器件误差，也会因镜像管 `VDS` 系统性不同而产生固定符号的输出电流差。共模输入通过有限尾源电阻产生共模电流，再经有源负载的不对称转换成差模输出；折算到输入即为系统性失调 `vosc`。

这种误差可由对称电压条件、较长沟道或反馈减小，但不能用“平均为零”的随机失配思路处理。CMOS Miller OTA 中内部节点的 `Delta VDS` 也可能成为主导系统性失调项。

来源：第 15 章 pp. 432-435，1523-1529。

# Class-AB 拓扑比较

Class-AB 拓扑不能只按最大输出电流排序。至少应共同比较：`Imax/IQ`、静态电流对电源与输出的敏感度、交越失真、输出摆幅、承载 AC 的器件数、补偿难度和最低供电。

交叉耦合与自适应偏置适合提高输入级压摆；跨线性环精确设定 `IQ` 但峰值受限；最小电流控制和 CMFB 协同可改善交越；局部误差放大与并联路径优先低失真；电流反馈和非等尺寸镜像追求电流效率；源跟随参考跨导器以最少交流器件获得最低供电。选择取决于负载、失真、速度和供电约束，不存在单一普遍最优结构。

来源：第 12 章 pp. 337-361，121-1248。

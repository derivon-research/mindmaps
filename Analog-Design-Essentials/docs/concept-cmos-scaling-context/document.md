# CMOS 缩放的技术经济背景

本章写作时（约 2004 年），CMOS 沟道长度持续缩短，使 CMOS 的可用增益频率不断上升，并在越来越宽的频段与双极型和 BiCMOS 工艺竞争。数字电路采用先进节点更快，而模拟/RF 设计通常滞后若干代，因为模拟器件常需更长沟道，同时小批量 MPW 在更先进节点的单位面积成本急剧增加。

这里的 90 nm、180 nm、10-40 GHz 等数值是源书时代的历史证据，不应当作 2026 年工艺现状。可复用的结论是：工艺缩放同时改变速度、增益、模型有效区间和成本，器件/工艺选择必须把性能收益与制造代价放在一起看。

来源：第 1 章，书页 2-4，幻灯片 013-017。

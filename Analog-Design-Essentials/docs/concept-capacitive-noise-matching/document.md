# 电容噪声匹配

电容传感器前置放大器中，输入管噪声通过电容比折算到传感器端，而输入管的 `C_GS` 又随宽度增加。宽度太小时 `g_m` 不足，太大时 `C_GS` 抬高噪声变换比，因此存在最优宽度。

书中的简化最优条件是 `C_GS,opt = C_sensor + C_feedback`。确定宽度后，再由工艺参数与选定过驱动得到电流和 `g_m`；实际设计可略取最优点左侧，以很小噪声代价显著节省面积。传感器与前置放大器应尽量共置，避免互连寄生电容。

来源：第 4 章 pp. 144-147，0453-0458。

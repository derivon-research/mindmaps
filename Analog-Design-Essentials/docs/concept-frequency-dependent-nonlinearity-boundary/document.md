# 频率相关非线性的幂级数边界

静态幂级数加相量法把非线性系数视为无记忆常数，只适合极点影响可单独处理的低至中频弱失真。高频下，电荷存储、内部节点动态和非线性同时作用，输出不再由瞬时输入的同一组 `a_n` 描述。

严格分析需用带记忆核的 Volterra 级数；其复杂度使它通常只用于较简单电路。工程上应把低阶幂级数结果视为有明确频率边界的近似，并用时域仿真与测量验证。

来源：第 18 章 pp. 561-562，图 18.86-18.88。

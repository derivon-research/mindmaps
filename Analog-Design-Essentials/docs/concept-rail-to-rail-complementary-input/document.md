# 互补轨到轨输入级

把 pMOST 输入的折叠级联和 nMOST 输入的折叠级联并联，一套覆盖低端电源轨，另一套覆盖高端电源轨，从而获得完整的轨到轨共模输入范围。

书中实例再接差分电流放大器和 class-AB 输出级，构成可单位增益连接的两级 Miller 运放。

第 11 章进一步指出，互补输入对是标准 CMOS 下覆盖两条输入电源轨的基础结构；是否必须让两套输入对同时导通，决定最低电源电压和后续跨导均衡方法。

来源：第 7 章 pp. 225, 231，0729、0741；第 11 章 pp. 301-305，111-119。

# Class-AB 输出级

Class-AB 互补输出级要求上下功率器件的栅极由同相交流电压驱动：信号朝一个方向变化时，一只管增强导通，另一只管减弱导通。这样可在较小静态电流下提供双向大输出电流。

其设计需分别处理交流增益路径和静态电流设定；偏置网络不能显著加载前级高阻节点。

第 12 章进一步把 Class-AB 定义为 Class-A 与 Class-B 之间的折衷：静态电流远小于峰值输出电流，却足以平滑两半周的交接。低压 CMOS 通常把上下输出管漏极相连，以牺牲开环输出电阻换取电容负载下的轨到轨摆幅；低输出电阻由反馈恢复。

关键规格包括静态电流的可预测性、`Imax/IQ` 驱动能力、扩张型大信号传输、交越失真、稳定性和实现复杂度。

来源：第 7 章 pp. 231, 233-234，0741、0744-0745；第 12 章 pp. 337-340，121-126。

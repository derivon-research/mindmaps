# 用复制 CMFB 保持弱反型总跨导

弱反型 `g_m` 与电流近似成正比，所以保持两对经 `n` 因子修正后的总电流即可保持总跨导。复制偏置在不触碰主信号节点的条件下给出两对平均电流；共模反馈把其和与 `4I_B` 比较，再反向联动 pMOST、nMOST 电流源。由于偏置误差会直接调制差分跨导，CMFB 的速度约束要求该环路至少跟上差分通道。

来源：第 11 章 pp. 315-320，1130-1138。边权 4：这是把器件区间定律、无扰测量、双极性控制和动态环路约束合成一个完整均衡机制的关键桥梁；各部分已分别由四个尾点显式承载，剩余步骤不可再拆成独立结论。

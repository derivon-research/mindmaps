# 由半跨导交越降低电源下限

互补输入余量下限说明宽重叠区为何耗费电压；弱反型电流开关和复制 CMFB 又能让每对跨导在交越附近受控下降。把目标改为“关断点等于接管点”，并令中点两对各贡献边缘值的一半，便无需同时维持两对满跨导，可把电源缩到约 `2(V_GS+V_DSsat)` 的实际交越值。

来源：第 11 章 pp. 319-321，1138-1140。边权 3.5：关键是把重叠要求改写为连续交接约束，并认识绝对阈值带来的设定不确定性。

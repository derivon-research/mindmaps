# 用电阻压降跨越常规阈值死区

互补输入余量表明在 1 V 中点，常规阈值 nMOST、pMOST 都可能截止。让受控电流流过串联电阻，可分别把两种输入管栅极向可导通方向移动；电流镜组成的复制共模发生器再令该电流只在死区附近出现。电阻热噪声与镜像失配同时给出这一余量交换的代价。

来源：第 11 章 pp. 332-334，1163-1167。边权 4：这是用动态模拟电平变换跨越阈值死区的完整构造，必须联合余量、噪声和电流复制；这些风险已作为尾点显式暴露，构造本身不可进一步拆解。

# 反相器 Class-AB 电源抑制限制

CMOS 反相器能直接利用平方律产生扩张型负载电流，但其 nMOST、pMOST 的 `VGS` 都由输入相对电源轨决定。静态电流因此强烈依赖电源电压。

数字电源尖峰会经两只管直接调制输出，书中把这种结构的 PSRR 近似视为 0 dB。它适合作为 Class-AB 原理单元，却不适合要求稳定静态电流和高电源抑制的精密驱动器。

来源：第 12 章 pp. 340-341，127-128。

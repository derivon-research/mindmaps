# 电流输入级 Class-AB 压摆

当输入峰值电流超过静态偏置 `I_B` 时，一侧输入 cascode 承担大电流，另一侧截止，前端进入 Class-AB 大信号工作。输出充放电电流约为 `B2*i_in`，所以

`SR = B2*i_in/C_L`。

压摆率不再受固定偏置电流硬限制，但越过静态工作区会产生失真。若必须保持线性，应令 `I_B` 大于输入峰值。

来源：第 10 章 pp. 292-293，104-105。

# 线性区输入跨导器

让输入 MOST 工作在线性区，并把其 (V_{DS}) 固定，可得到近似线性的电压-电流关系：

[
I_Dapprox eta V_{DS}(V_{GS}-V_T),qquad
g_m=eta V_{DS}.
]

书中用恒流 (I_D) 在电阻 (R_D) 上建立约 0.2 V 的固定压降，从而保持 (V_{DS}) 和跨导近似恒定。代价是跨导和增益低于饱和区方案。

来源：第 7 章 pp. 230-231，0740。

# 双极型基极电流补偿

双极型输入管的基极电流约为 `IC/beta`，可用一只匹配复制管感知其基流，再经电流镜注回两个输入端。为提高精度，复制管应与输入管具有相同电流、`beta` 和 `VCE`；自举钳位可让这些电压随输入共模一起移动。

左右各自补偿会把两套辅助电路噪声直接注入差分输入。更好的结构使用一个共用基流发生器，其公共噪声在差分输出相消，只留下少数非共模支路的噪声。

来源：第 15 章 pp. 450-453，1558-1563。

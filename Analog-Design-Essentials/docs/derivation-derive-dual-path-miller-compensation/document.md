# 为互补折叠路径分别保留 Miller 反馈

两级 Miller 运放要求从第二级输出向当前有效的一级高阻节点反馈。互补输入结构在两条电源轨附近会关闭其中一条折叠路径，因此单只电容不能覆盖全部共模范围；给两条路径各接一只电容即可在任一输入对工作时保持极点分裂。同时依据普通 Miller 前馈机理检查电容是否绕过级联管并引入右半平面零点。

来源：第 11 章 pp. 314，318-319，1127、1135-1136。边权 3.5：需把分段有效的信号路径映射为分段有效的补偿路径，并同时审查零点。

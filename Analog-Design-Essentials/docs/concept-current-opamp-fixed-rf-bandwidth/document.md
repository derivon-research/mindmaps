# 固定 RF 的电流运放带宽

保持 `R_F` 不变、用 `R_S` 调整增益时，一阶带宽

`BW = 1/(2*pi*R_FC_c)`

近似不随闭环增益改变。减小 `R_S` 即可提高 `R_F/R_S`，因此在理想模型中能同时取得高增益和高带宽；书中例子在增益 1000 时由 32 kHz 提高到约 1.6 MHz。

这一优势最终受前端有限输入电阻限制，不是无限可扩展。

来源：第 10 章 pp. 295-296，109-1011。

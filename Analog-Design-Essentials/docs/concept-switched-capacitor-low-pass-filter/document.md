# 开关电容低通滤波器

把有源 RC 低通中的电阻换成开关电容后，低频增益与截止频率都由电容比决定：源书例中 `Av0=C1/C2`，`f-3dB=(fc/2pi)*(C2/C)`。晶体时钟给出准确的绝对频率，匹配电容给出准确的比例，因此可集成原本需要大电阻的低频滤波器。

适用边界是信号频率远低于 `fc`，并且所需频率比不能迫使电容比过大；最小单位电容还受寄生、匹配和噪声限制。

来源：第 17 章 pp. 486-488，图 17.4-17.7。

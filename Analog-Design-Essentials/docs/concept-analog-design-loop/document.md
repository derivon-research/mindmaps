# 模拟设计的手算-仿真闭环

模拟集成电路设计同时需要创造性的折衷和可重复的方法。这里的基本闭环是：先用足够简单的小信号手算模型预测性能、确定晶体管电流与尺寸，再用 SPICE、ELDO 或 SPECTRE 中更完整的器件模型验证；若验证不满足规格，就回到手算假设与设计选择继续迭代。

手算模型的价值不是高精度，而是让设计者看见尺寸、电流和性能之间的因果关系。仿真模型的价值是补入手算中忽略的二阶效应。只做其中一步都不能形成作者所说的真实设计流程。

本 Mindmap 面向具备基础电路与晶体管知识、正在学习模拟集成电路设计的中文读者；后续边权均按这一受众估计。

来源：Willy M. C. Sansen, *Analog Design Essentials*, 第 1 章，书页 1-2，幻灯片 011-012。

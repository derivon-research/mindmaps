# 对称 OTA 的非主极点

对称 OTA 的节点 1、2 在差分模下共同形成一个非主极点；其电阻约为 (1/g_{m4})，节点电容包含镜像管按 (B) 放大的输入电容。粗略写成：

[

]

另一侧节点 5 产生的是展宽比约为 2 的极零双点，对相位裕度影响很小。因此三个低阻内部节点最终只留下一个主要非主极点。

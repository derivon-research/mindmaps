# 单管局部串联反馈

在源极加入电阻 `RS` 形成局部串联负反馈，环路因子约为 `1+gm*RS`。闭环跨导降为 `gm/(1+gmRS)`，输出电阻提高为约 `rDS(1+gmRS)`，输入栅源电容效应也按相同因子减小。

增益的降低与输出电阻的提高相抵，低频电压增益可近似保持；代价是实际源电阻产生额外噪声。用电感代替电阻可在指定频带提供无热噪声的局部反馈，但频率响应随之变化。

来源：第 2 章 pp. 57-59，0214-0216。

# 跨线性 Class-AB 偏置

四只匹配 MOST 可组成栅源电压和相等的跨线性环：

[
V_{GS2}+V_{GS4}=V_{GS9}+V_{GS10}.
]

当其中三支电流由电流源固定后，第四支输出管的静态电流也被尺寸比确定。书中尺寸关系使输出管静态电流约为偏置支路的 100 倍，从而用小电流准确控制大输出器件。

环式中的 `VT` 和工艺系数可相消，因此静态电流主要由电流与尺寸比决定，而不直接随电源电压变化。它的峰值输出能力却可能受限：某支电流必须趋近零后另一支才显著增大，关断还会加剧交越失真和速度损失。

来源：第 7 章 pp. 233-234，0745；第 12 章 pp. 346-354，1220-1234。

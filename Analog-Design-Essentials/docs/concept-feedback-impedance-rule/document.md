# 反馈阻抗缩放规律

负反馈使串联端口的阻抗约乘 `1+T`，使并联端口的阻抗约除以 `1+T`，其中 `T` 为环路增益。于是输入串联提高输入阻抗，输入并联降低输入阻抗；输出串联提高输出阻抗，输出并联降低输出阻抗。

直观上，并联反馈增加端口总电流而降低 `v/i`，串联反馈增加端口总电压而提高 `v/i`。计算开环端口阻抗时须把受控增益置零，再施加端口测试源。

来源：第 13 章 pp. 365，368-374，134、1310-1322。

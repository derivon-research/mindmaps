# 无电阻 MOST 电流基准

上下对接的 MOST 电流镜可用沟道本身充当非线性电阻。尺寸比 `a`、`b` 与一个 PTAT 栅压差 `V2` 设定非零工作点，同时零电流仍是另一平衡点。

输出强烈依赖 `K'`、尺寸比和 `V2`。若 `K'~T^-1.5` 而 `V2~T`，电流约呈 `T^-0.5`；绝对精度受迁移率和失配限制。源书用五个弱反型 PTAT 单元串联得到约 0.32 V，使电流散布可低至约 5%。

来源：第 16 章 pp. 480-481，1647-1648。

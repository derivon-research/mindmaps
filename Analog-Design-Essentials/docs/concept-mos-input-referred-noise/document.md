# MOST 等效输入噪声

把漏端沟道噪声除以跨导平方折算到栅端，得到 `S_v,in = 4kT gamma/g_m`；若栅电阻不可忽略，还要加上 `4kTR_G`。增大 `g_m` 可降低沟道输入噪声，但通常需要更小过驱动、更大 `W/L` 或更大电流。

在接近 `f_T` 的高频范围，栅源电容还会产生与输入电压噪声相关的噪声电流，二者不能按不相关功率简单相加。

来源：第 4 章 pp. 123-125，0413-0415。

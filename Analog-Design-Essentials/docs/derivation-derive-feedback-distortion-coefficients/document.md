# 消元得到反馈闭环非线性系数

对非线性放大器写 `u=x-Fy` 与 `y=a1u+a2u^2+a3u^3+...`，逐阶代入并消去内部量 `u`；比较闭环 `y=d1x+d2x^2+d3x^3+...` 的同次幂系数，得到 `d2` 的三次环路分母，以及同时包含 `a3` 与 `a2` 再循环项的 `d3`。

来源：第 18 章 pp. 542-544，图 18.47-18.50。边权 4.5：逐阶隐式消元且三阶含交叉贡献，是本章核心推导。

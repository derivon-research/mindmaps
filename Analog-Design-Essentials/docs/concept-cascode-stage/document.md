# 共栅级联管

级联管（cascode）从源端接收小信号电流、从漏端输出，栅端交流接地。低负载阻抗时输入电阻约为 `1/gm`，电流增益近似 1，所以它是电流缓冲器；其核心作用是隔离输入器件漏端电压并提高整体输出电阻。

级联管与共源放大器、源跟随器构成三种基本单管功能：电压转电流、单位电压缓冲、单位电流缓冲。具体输入/输出阻抗会随信号源和负载有限电阻改变。

来源：第 2 章 pp. 68、75-77、84-87，0236、0248-0252、0266-0271。

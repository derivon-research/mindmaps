# 简化反馈方程适用边界

常用的 `1+T` 阻抗缩放要求反馈网络不会显著改变断环前后的端口加载。若反馈电阻与输出 `ro` 同量级，或与 BJT 的 `rpi` 强烈分流，输入加载与输出加载会彼此耦合，粗略环路增益和阻抗公式不再可靠。

这时应把晶体管替换为完整小信号等效电路，直接列 KCL/KVL，或用 SPICE 验证；闭环跨阻 `RF` 往往仍是较好的第一近似。

来源：第 14 章 pp. 397-403，1417-1429。

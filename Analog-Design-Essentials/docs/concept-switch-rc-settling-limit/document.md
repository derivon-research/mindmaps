# 开关 RC 建立上限

开关以 `Ron` 给电容充电时，误差 `epsilon` 所需建立时间为 `ts=Ron*C*ln(1/epsilon)`；0.1% 约需 `7RonC`。若每相位最多半个周期，必须满足 `Tc/2>=ts`，从而限制最高时钟频率。

源书用 `Ron=10 kohm`、`C=1 pF` 得到 `ts=70 ns` 与约 7 MHz。增大开关可提速，却会增加注入电荷；增大电容可降噪，却会减慢建立。

来源：第 17 章 pp. 493-495，图 17.19-17.20。

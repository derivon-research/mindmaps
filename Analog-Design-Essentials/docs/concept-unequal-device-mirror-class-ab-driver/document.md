# 非等尺寸镜像 Class-AB 驱动器

非等尺寸镜像驱动器用两组倍率为 `b` 的电流镜和尺寸不同的并联输入管产生 Class-AB 电流。若一只输入管为另一只的 `1+a` 倍，并以 `aI` 设定镜像偏置，两侧静态电流可由尺寸比和参考电流明确确定。

驱动节点可有很大电压摆幅，输出电流远超静态值。大信号时级联管限制镜像管 `VDS`，后者进入线性区并使电流增长趋缓，但峰值能力仍高于普通跨线性环。

来源：第 12 章 pp. 357-358，1240-1241。

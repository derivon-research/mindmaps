# 源跟随器高频响应

加入晶体管电容、信号源电阻和负载后，源跟随器包含两个极点和一个零点。以 `gm`（亦即偏置电流）为参数时，中间电流区可出现一对复极点，引起电压增益和输出阻抗峰化；更高电流下零点先于极点，输出阻抗呈感性。

最优偏置不是“电流越大越快”。把 `gm` 调到零点抵消第一极点的 `gmu`，可获得近似一阶、宽带且电阻性的输出；在栅端增加补偿电容相当于先加低通，可缩小复极点区。

来源：第 2 章 pp. 71-73，0241-0244。

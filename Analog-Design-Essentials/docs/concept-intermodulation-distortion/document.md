# 互调失真

两个相近频率、等幅单音共同通过弱非线性时，会产生和频、差频及 `2*omega1-omega2`、`2*omega2-omega1` 等组合频率。低阶近似为

`IM2 = (a2/a1)*U = 2*HD2`，

`IM3 = (3/4)*(a3/a1)*U^2 = 3*HD3`。

三阶互调产物紧邻原信号，通常无法用后续选频滤波器去除，因此在通信接收链中尤其关键。

来源：第 18 章 pp. 525-528，图 18.15-18.20。

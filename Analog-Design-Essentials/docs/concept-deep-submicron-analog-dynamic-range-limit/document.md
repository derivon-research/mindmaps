# 深亚微米 CMOS 动态范围收缩

工艺缩放使供电和最大信号摆幅下降；若仍使用最小面积器件，`sigma(Delta VT)=AVT/sqrt(WL)` 反而可能上升。把若干倍失配留作成品率裕量后，可用信号范围被两端同时挤压。

源书基于当时路线图警告 90 nm 以下最小器件的模拟动态范围可能趋近很小。其可复用结论不是节点数值，而是：高动态范围模拟块必须保留较高供电、降低允许失真或使用远大于最小尺寸的器件，因此在混合信号芯片中占用更大面积。

来源：第 15 章 pp. 454-455，1567-1568。

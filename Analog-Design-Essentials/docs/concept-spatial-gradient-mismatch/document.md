# 芯片空间梯度失配

除局部随机涨落外，温度、机械应力、氧化层厚度、掺杂和刻蚀量还会随芯片位置缓慢变化。相隔器件采样到不同的局部环境，便产生带方向和位置相关性的失配。

现代大晶圆工艺改善了短距离均匀性，所以距离本身未必是首要指标；当器件阵列覆盖较大面积时，空间梯度仍会限制高精度比例。版图设计应让匹配对象采样相同或对称的空间环境。

来源：第 15 章 pp. 426、438、442-443，1510、1534-1535、1543。

# EKV 平滑过渡模型

EKV 模型用包含指数和对数的单一连续函数连接弱反型指数律与强反型平方律，而不是让器件在两个分段模型之间跳变。用 `IDSt` 归一化电流、用约 `2nUT` 归一化过驱动后，模型的低电压极限还原指数式，高电压极限还原平方律。

这个模型的核心价值是电流和跨导在中等反型区连续，并可直接用反型系数表达设计点。源书同时提醒：`n` 仍随偏置变化，模型是比简单分段式更一致的手算桥梁，并非代替工艺提供的精确模型。

来源：第 1 章，书页 20-23，幻灯片 0137-0141；模型归因于 Enz 等人的 EKV 工作。

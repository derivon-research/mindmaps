# 电流反馈运放

电流反馈运放以电流输入级取代两级电压运放的输入跨导级，并通过 `R_S`、`R_F` 闭合反馈。低频闭环电压增益仍为 `-R_F/R_S`，但反馈电阻直接参与主极点时间常数。

书中的一阶式为

`A_VI = -(R_F/R_S)/[1+j*omega*R_F*C_c]`。

因此同一电路可通过选择固定哪一只电阻，表现为恒增益带宽积或近似恒带宽。

来源：第 10 章 pp. 294-296，107-1011。

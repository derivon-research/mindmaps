# 用示性函数积分重写零点和

对每个零点 $z_k$ ，令 $\eta_k(r)=1$ 当 $r>|z_k|$ ，否则为 $0$ 。于是 $n_f(r)=\sum_k\eta_k(r)$ ，且

$$\int_0^R\eta_k(r)\frac{dr}{r}=\log\frac R{|z_k|}.$$

有限求和与积分交换后，Jensen 公式中的零点对数和正好变成 $\int_0^Rn_f(r)dr/r$ 。

**认知成本：1.5/5**。核心是用径向示性函数表示每个零点何时进入圆盘。**来源**：第二卷第 5 章 Lemma 1.2 与公式 (2)，书页 137–138（PDF 482–483）。

# 以 Weierstrass 基函数逐点插值并压低尾项

设 $E$ 是以 $a_k$ 为简单零点的 Weierstrass 乘积。函数

$$\frac{E(z)}{E'(a_k)(z-a_k)}$$

在 $a_k$ 取 $1$ ，在其余节点取 $0$ 。再乘 $(z/a_k)^{m_k}$ 不改变这些节点值，却可逐项选择足够大的 $m_k$ ，使第 $k$ 项在前 $k$ 个紧圆盘上的模小于 $2^{-k}$ 。加上原点项后所得级数紧一致收敛为整函数，并逐点取得 $b_k$ 。

**认知成本：4/5**。无穷插值的核心是保留 Kronecker 节点值，同时用可调幂次对角压低尾项。**来源**：第二卷第 5 章 Exercise 17(b)，书页 156（PDF 501）。

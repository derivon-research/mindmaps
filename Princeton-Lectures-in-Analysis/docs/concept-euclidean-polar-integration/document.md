# Euclidean 空间的极坐标积分

对适度衰减函数，

$$
\int_{\mathbb R^d}f(x)\,dx
=\int_{S^{d-1}}\int_0^\infty f(r\gamma)r^{d-1}\,dr\,d\sigma(\gamma).
$$

其中  $d\sigma$  是单位球面的面积元。该式先由高维球坐标的 Jacobian 在有限球上成立，再对适度衰减函数令球半径趋于无穷；旋转换元还给出  $d\sigma$  的旋转不变性。

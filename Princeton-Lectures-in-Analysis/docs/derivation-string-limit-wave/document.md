# 从离散弦到一维波动方程

离散质点模型给第 $n$ 个质点质量 $\rho h$ ，左右张力合力为

$$\frac{\tau}{h}(y_{n+1}+y_{n-1}-2y_n).$$

牛顿第二定律令它等于 $\rho h y_n''$ 。除以 $h$ 后，以 $y_n=u(x_n,t)$ 代入；二阶中心差分极限把括号除以 $h^2$ 的表达送到 $u_{xx}$ 。令 $h\to0$ 得 $\rho u_{tt}=\tau u_{xx}$ ，即速度 $c=\sqrt{\tau/\rho}$ 的波动方程。

离散模型规定质量与局部力，牛顿定律提供动力学等式，中心差分极限完成离散到连续的桥接。

**认知成本：4/5**。关键难点是识别尺度、正确除以 $h$ 并理解连续极限；本章将其作为可信建模而非严格极限定理。**来源**：书页 6–8（PDF 23–25）。

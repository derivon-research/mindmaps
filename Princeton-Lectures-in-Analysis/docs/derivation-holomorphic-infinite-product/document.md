# 在紧集上统一控制乘积尾部

标量无穷乘积定理逐点保证收敛。对尾乘积展开

$$\prod_{n=N}^M(1+u_n),$$

并用 $\prod(1+|u_n|)\le\exp(\sum|u_n|)$ ，可把尾部与 $1$ 的距离由 $\sum_{n\ge N}c_n$ 一致控制。故部分乘积在紧集上一致 Cauchy；全纯极限定理给出全纯性。若极限在一点为零而所有因子非零，则从任意有限首段之后的尾乘积都应有非零极限，矛盾。

**认知成本：2.5/5**。需把标量对数论证升级为紧集一致估计，并排除新零点。**来源**：第二卷第 5 章 Proposition 3.2，书页 141–142（PDF 486–487）。

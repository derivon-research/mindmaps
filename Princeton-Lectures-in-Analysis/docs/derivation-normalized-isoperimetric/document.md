# 用 Parseval 证明归一化面积上界

弧长条件给 $x'^2+y'^2=1$ 。对 $x,y$ 的傅里叶系数应用导数法则与 Parseval，得到 $\sum n^2(|a_n|^2+|b_n|^2)=1$ 。极化 Parseval 把面积写成系数的双线性和；逐项用 $2|a_n||b_n|\le|a_n|^2+|b_n|^2$ ，再用 $|n|\le n^2$ ，得 $A\le\pi$ 。

等号审查不能省略： $|n|<n^2$ 对 $|n|\ge2$ 严格，故只剩 $0,\pm1$ 频率。

**认知成本：3.5/5**。跨越几何归一化、两个 Parseval 公式和等号链，但每一步已显式展开。**来源**：第一卷第 4 章 Theorem 1.1，书页 104–105（PDF 121–122）。

# 外三角域上 Dirichlet 问题的可解性的第三卷推导

先对光滑延拓数据用正交投影构造内部调和 $u$ 。局部 Poincaré 估计作用于 $F-u$ ，再以小球平均和 Cauchy–Schwarz 说明 $u(z)$ 在 $z\to y\in\partial\Omega$ 时趋于 $F(y)$ ；积分绝对连续性使局部梯度能量消失。一般连续数据以光滑边界数据一致逼近，最大值原理使对应调和解一致 Cauchy，紧致一致极限仍调和并取得边值；唯一性同样由最大值原理。

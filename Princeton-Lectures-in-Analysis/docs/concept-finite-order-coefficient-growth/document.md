# 有限阶整函数的系数判据

设 $F(z)=\sum_{n\ge0}a_nz^n$ 。若

$$|F(z)|\le A e^{a|z|^\rho},$$

则

$$\limsup_{n\to\infty}|a_n|^{1/n}n^{1/\rho}<\infty.$$

反之，若该上极限有限，则对每个 $\varepsilon>0$ 都有常数 $A_\varepsilon,a_\varepsilon$ 使

$$|F(z)|\le A_\varepsilon e^{a_\varepsilon|z|^{\rho+\varepsilon}}.$$

因此 Taylor 系数的衰减尺度刻画整函数的增长阶。

**来源**：第二卷第 5 章 Problem 4，书页 157–158（PDF 物理页 502–503）。

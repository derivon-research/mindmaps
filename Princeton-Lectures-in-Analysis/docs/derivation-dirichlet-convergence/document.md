# 从延迟平均转回普通部分和

Fejér 定理与恒等式表达保证固定 $k$ 时 $\sigma_{kn,n}(f)\to f$ ；若 $\widehat f(\nu)=O(1/|\nu|)$ ，过渡带求和给 $|\sigma_{kn,n}-S_m|\le C/k$ ，对所有 $kn\le m<(k+1)n$ 一致。先取大 $k$ 压低比较误差，再取大 $n$ 使用平均收敛，即得所有部分和一致趋于 $f$ 。

**认知成本：2.5/5**。是一个两参数 $\varepsilon$ 论证，关键输入已拆成两个节点。**来源**：第一卷第 4 章问题 5(b)–(d)、问题 6，书页 128（PDF 145）。

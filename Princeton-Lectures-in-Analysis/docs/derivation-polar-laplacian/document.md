# 用链式法则改写拉普拉斯算子

令 $x=r\cos\theta$ 、 $y=r\sin\theta$ ，用链式法则把 $\partial_x,\partial_y$ 表为 $\partial_r,\partial_\theta$ 的组合。再次求导并相加时，交叉项抵消，余下

$$\Delta=\partial_{rr}+r^{-1}\partial_r+r^{-2}\partial_{\theta\theta}.$$

拉普拉斯算子给出待改写对象；变换本身是为了适配圆盘几何。

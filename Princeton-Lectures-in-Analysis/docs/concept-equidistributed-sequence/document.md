# 等分布序列

序列 $\{\xi_n\}\subset[0,1)$ 称为等分布，若每个区间 $(a,b)\subset[0,1)$ 都满足

$$\frac{\#\{1\le n\le N:\xi_n\in(a,b)\}}N\longrightarrow b-a.$$

等分布比稠密强：它不仅要求命中每个子区间，还要求长期出现比例等于区间长度。项的排列顺序会影响这一性质。

本章练习给出边界例子。若 $\theta=p/q$ 为既约有理数，则 $\langle n\theta\rangle$ 只在 $q$ 个格点 $0,1/q,\ldots,(q-1)/q$ 上循环，并以误差 $O(1/N)$ 等频出现，但不在整个区间上等分布。黄金比幂的小数部分也不是等分布；稠密的有理数枚举若把一半项固定在零点，同样不是等分布。

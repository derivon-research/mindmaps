# 普通多项式的一致逼近

Weierstrass 逼近定理断言：闭区间 $[a,b]$ 上的每个连续函数都能由普通代数多项式一致逼近。

第二章练习 16 从周期三角多项式逼近出发，再把每个复指数在紧区间上由其幂级数多项式一致逼近，从而得到该结论。

第五章给出另一条实线 Fourier 分析路线：先将函数延拓成紧支撑连续函数并用窄高斯卷积一致逼近，再在有关紧区间用高斯的幂级数截断逼近卷积核；与紧支撑函数卷积后，截断核产生关于 $x$ 的普通多项式。这一路线与第二章的三角多项式证明平行。

# 以指数级数比较并用单项给反向界

由 $n^n\ge n!$ 及指数级数估计，可把

$$\sum_n\frac{r^n}{(n!)^\alpha}$$

控制为 $C\exp(Cr^{1/\alpha})$ ，得到阶至多 $1/\alpha$ 。反之，若阶小于 $1/\alpha$ ，Cauchy 系数估计会迫使 $(n!)^{-\alpha}$ 比其实际尺度衰减更快；或在正实轴选择 $n\asymp r^{1/\alpha}$ 的单项即可产生矛盾。

**认知成本：3/5**。上下界分别需要整级数比较与最优单项选择。**来源**：第二卷第 5 章 Problem 3，书页 157（PDF 502）。

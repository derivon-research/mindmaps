# 拨弦运动

拨弦运动可写成驻波叠加

$$u(x,t)=\sum_{m=1}^{\infty}\frac{2h\sin(mp)}{m^2p(\pi-p)}\cos(mt)\sin(mx),$$

也可写成两个反向传播轮廓的平均

$$u(x,t)=\frac{f(x+t)+f(x-t)}2,$$

其中 $f$ 作奇的 $2\pi$ 周期延拓。两式由 $\cos v\sin u=[\sin(u+v)+\sin(u-v)]/2$ 相联。

第二章练习 3 补上第一章暂缺的严格性： $|A_m|\le C/m^2$ 使级数绝对且一致收敛；所得连续函数具有与初始轮廓相同的傅里叶系数，再由唯一性定理确认级数确实等于 $f$ 。

# 圆盘 Dirichlet 问题的 Poisson 积分解

边界数据为 $f$ 时，定义

$$u(r,\theta)=(f*P_r)(\theta)=\frac1{2\pi}\int_{-\pi}^{\pi}f(\varphi)P_r(\theta-\varphi)\,d\varphi.$$

在圆盘内部，它可逐项二次求导并满足 $\Delta u=0$ ；在 $f$ 的每个连续边界点趋于 $f$ ，连续边界数据时收敛一致。

第二卷还从 Cauchy 积分公式导出同一表示：先为调和函数构造共轭调和函数，再取 Cauchy 边界公式的实部。

第三章 Problem 2 又从圆心平均值性质出发，用交换 $0$ 与目标点的圆盘自同构恢复同一 Poisson 表示。

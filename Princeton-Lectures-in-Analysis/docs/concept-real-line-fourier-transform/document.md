# 实直线 Fourier 变换

对适度衰减函数，Fourier 变换定义为

$$\widehat f(\xi)=\int_{-\infty}^{\infty}f(x)e^{-2\pi ix\xi}\,dx.$$

它是圆周傅里叶系数的连续频率版本：整数 $n$ 被实频率 $\xi$ 取代，求和与有限区间积分分别变为积分与全实线积分。定义立即给 $\widehat f$ 有界；练习 5 由平移连续性证明它连续且在无穷远趋零。

**边界**：仅有适度衰减并不保证 $\widehat f$ 也适度衰减，所以反演公式尚不能只靠定义成立。

**来源**：第一卷第 5 章 §1.2、练习 5，书页 134、162–163（PDF 151、179–180）。

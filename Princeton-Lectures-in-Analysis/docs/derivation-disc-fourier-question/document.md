# 圆盘边界数据再次引出傅里叶表示

圆盘调和模态在边界 $r=1$ 上变成 $e^{im\theta}$ 。线性叠加给形式解 $u(r,\theta)=\sum a_mr^{|m|}e^{im\theta}$ ；Dirichlet 边界条件要求

$$f(\theta)=u(1,\theta)=\sum_{m\in\mathbb Z}a_me^{im\theta}.$$

模态给出可用内部解，叠加原理组合它们，边界问题要求组合匹配任意 $f$ 。这是一条独立于弦振动的平行路线，导向同一傅里叶表示问题。

**认知成本：2.5/5**。关键是把内部调和延拓的边界迹认成复指数级数。**来源**：书页 22–23（PDF 39–40）。

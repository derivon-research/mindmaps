# 二进疏函数的处处不可微性

对 $0<\alpha<1$ ，连续函数

$$f_\alpha(x)=\sum_{n\ge0}2^{-n\alpha}e^{i2^nx}$$

在每一点都不可微。若它在 $x_0$ 可微，延迟平均导数的相邻尺度差应为 $O(\log N)$ ；频块抽取却给其绝对值

$$2^{n(1-\alpha)}\ge cN^{1-\alpha},$$

而正幂增长快于对数，矛盾。书中还通过允许 $|h|\le c/N$ 的局部版本说明其实部与虚部分别也处处不可微。

第五章问题 8 处理第四章方法没有覆盖的临界端点 $\alpha=1$ 。它用光滑频率截断和 Poisson 求和构造有限三角多项式核；若某点可微，卷积导数应趋于真实导数，但相邻二进模态保持固定振幅，迫使极限失败。这个细化同样分别排除实部和虚部在任何一点可微。

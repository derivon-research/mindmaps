# Abel 可和性

级数 $\sum_{k\ge0}c_k$ 若对每个 $0\le r<1$ 的幂级数 $A(r)=\sum c_kr^k$ 收敛，且 $A(r)\to s$ 当 $r\uparrow1$ ，则称原级数 Abel 可和到 $s$ 。

普通收敛蕴含 Cesàro 可和，Cesàro 可和又蕴含同值的 Abel 可和；反向均可能失败。练习 13 用 Abel 变换式证明这些包含关系。

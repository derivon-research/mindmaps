# 以递减开邻域逼近紧集与其和

令 $A^\varepsilon=\{d(x,A)<\varepsilon\}$ ，类似定义 $B^\varepsilon$ 。有 $A+B\subset A^\varepsilon+B^\varepsilon\subset(A+B)^{2\varepsilon}$ ；这些开邻域随 $\varepsilon\downarrow0$ 递减到相应紧集。对开集应用不等式，再用有限测度下的从上连续性取极限。

**认知成本：3.5/5**。需要和集邻域夹逼与三组递减测度极限同步。**来源**：第三卷第 1 章 Theorem 5.1，书页 37（PDF 物理页 782）。

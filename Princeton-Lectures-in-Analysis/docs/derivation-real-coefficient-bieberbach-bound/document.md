# 用上半圆盘虚部的符号控制 Fourier 系数

实系数使 $f(\overline z)=\overline{f(z)}$ ，单叶性迫使上半圆盘映到像域实轴的一侧；近原点的 $\operatorname{Im}f(re^{i\theta})\sim r\sin\theta$ 确定其符号。把 $a_nr^n$ 写为该虚部的正弦系数，配合 $|\sin n\theta|\le n\sin\theta$ 得 $|a_n|r^n\le nr$ ，令 $r\uparrow1$ 。

**认知成本：4/5**。把几何单叶性、反射对称与 Fourier 系数估计结合。**来源**：第二卷第 8 章 Problem 8，书页 259（PDF 604）。

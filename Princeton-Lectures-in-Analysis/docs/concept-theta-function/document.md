# Theta 函数

对 $s>0$ ，定义

$$\vartheta(s)=\sum_{n\in\mathbb Z}e^{-\pi n^2s}.$$

级数绝对收敛。更一般的 Jacobi theta 函数
$\Theta(z\mid\tau)=\sum_ne^{i\pi n^2\tau}e^{2\pi inz}$ 在 $\operatorname{Im}\tau>0$ 定义；取 $z=0,\tau=is$ 即回到 $\vartheta(s)$ 。圆周热核满足 $H_t(x)=\Theta(x\mid4\pi it)$ 。

**来源**：第一卷第 5 章 §3.1–3.2，书页 155–156（PDF 172–173）。

固定 $\operatorname{Im}\tau>0$ 后，第二卷第五章把 $\Theta(z\mid\tau)$ 视为 $z$ 的整函数，并证明其增长阶恰为 $2$ 。

**补充来源**：第二卷第 5 章 Exercise 3，书页 153（PDF 物理页 498）。

# Riemann 可积函数

区间上的有界实函数 $f$ 称为 Riemann 可积，如果对任意 $\varepsilon>0$ ，存在一个分割使相应上和与下和之差小于 $\varepsilon$ 。复值函数可积是指其实部、虚部分别可积。

本卷默认所有函数至少 Riemann 可积。这一类允许无穷多个不连续点；积分附录证明了精确判别：闭区间上的有界函数 Riemann 可积，当且仅当其不连续点集为零测集。第二章问题 1 给出不连续点稠密的例子。本点不采用第三卷才引入的 Lebesgue 可积含义。

**来源**：第 2 章，书页 30–33；问题 1，书页 65–66（PDF 47–50、82–83）；积分附录 §1、Theorem 1.7，书页 281–289（PDF 298–306）。

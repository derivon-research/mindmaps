# 二进疏级数函数

对 $0<\alpha<1$ ，定义

$$f_\alpha(x)=\sum_{n=0}^\infty2^{-n\alpha}e^{i2^nx}.$$

系数构成收敛几何级数，所以由 Weierstrass 判别法级数一致绝对收敛， $f_\alpha$ 连续。频率只取 $2^n$ ，故它是高度疏的傅里叶级数。

当 $\alpha>1$ 时可逐项求导； $0<\alpha<1$ 时本章证明它处处不可微。 $\alpha=1$ 需要第五章更精细的方法。

**来源**：第一卷第 4 章 Theorem 3.1 与其后说明，书页 114、118（PDF 131、135）。

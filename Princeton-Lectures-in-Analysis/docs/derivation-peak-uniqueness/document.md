# 用峰值多项式证明傅里叶唯一性

假设所有傅里叶系数为零而 $f$ 在某连续点非零。平移、变号后可令该点为 0 且 $f(0)>0$ 。峰值多项式 $p_k=(\varepsilon+\cos\theta)^k$ 在小邻域指数增长，在外部指数衰减。由于 $p_k$ 是有限频率组合，零系数假设迫使 $\int fp_k=0$ ；但连续性给小邻域上的正下界，积分反而趋于正无穷，矛盾。

Riemann 可积性提供全局有界，峰值族隔离连续点，傅里叶系数定义使所有三角多项式矩都为零。

**认知成本：4/5**。核心构造及内外区域的竞争估计都非显然。**来源**：Theorem 2.1，书页 39–41（PDF 56–58）。

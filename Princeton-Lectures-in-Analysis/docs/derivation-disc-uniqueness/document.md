# 用径向傅里叶系数证明圆盘解唯一

设另一调和函数 $v$ 一致趋于同一连续边界数据。固定 $r$ 对角变量取傅里叶系数 $a_n(r)$ ；把调和方程乘 $e^{-in\theta}$ 积分，分部两次得到径向 Euler 方程。原点有界排除 $r^{-|n|}$ ，边界一致收敛确定余下常数为 $\widehat f(n)$ 。于是 $v$ 与 Poisson 解在每个圆周上系数相同，再用傅里叶唯一性得到相等。

Poisson 解提供比较对象，傅里叶唯一性把每个固定半径上的系数一致升级为函数一致。

**认知成本：4/5**。关键桥梁是对 PDE 取角向傅里叶系数并解径向 ODE。**来源**：Theorem 5.7(iii)，书页 57–58（PDF 74–75）。

# 用 Fourier 变换解上半平面 Dirichlet 问题

对 $x$ 变换后，调和方程变为 $\widehat u_{yy}-4\pi^2\xi^2\widehat u=0$ 。舍去随 $y$ 增长的支，边界条件给
$\widehat u=\widehat f e^{-2\pi|\xi|y}$ ；卷积定理识别为 $f*P_y$ 。Poisson 核好核性质给一致边界恢复，Plancherel 给均方恢复。

**认知成本：3/5**。包含频率 ODE 的分支选择、卷积识别和边界极限。**来源**：第一卷第 5 章 Theorem 2.6，书页 149–151（PDF 166–168）。

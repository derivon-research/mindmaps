# Riemann zeta 函数的亚纯延拓

$\zeta(s)$ 唯一亚纯延拓到整个复平面，唯一奇点是 $s=1$ 处的简单极点。 $s=0$ 处完备函数的极点被 $1/\Gamma(s/2)$ 的零点抵消。

**来源**：第二卷第 6 章 Theorem 2.4，书页 172（PDF 517）。

第七章把 $s=1$ 的简单极点写成 $\zeta(s)=1/(s-1)+H(s)$ ，从而得到 $-\zeta'(s)/\zeta(s)=1/(s-1)+h(s)$ ；这一局部形式在 Chebyshev 围道变形中产生主项 $x^2/2$ 。

**补充来源**：第二卷第 7 章 §2.1，书页 195–197（PDF 物理页 540–542）。

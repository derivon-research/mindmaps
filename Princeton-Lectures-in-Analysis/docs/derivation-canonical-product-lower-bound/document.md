# 分近零点与远零点控制对数模

把因子按 $|a_n|\le2|z|$ 与 $|a_n|>2|z|$ 分组。远因子用 $\log E_k$ 的可和尾项估计；近因子数由 $n(2|z|)\le C|z|^s$ 控制。对近因子，避开圆盘 $|z-a_n|<|a_n|^{-k-1}$ 保证 $1-z/a_n$ 不会过小，再把指数项与对数项逐一估计。合并得到

$$-\log\left|\prod_nE_k(z/a_n)\right|\le C|z|^{s'}$$

其中 $s'$ 可任取略大于零点收敛指数的数。

**认知成本：4/5**。主要技巧是按相对尺度拆分乘积，并同时使用零点密度和避零距离。**来源**：第二卷第 5 章 Lemmas 5.2–5.3，书页 148–150（PDF 493–495）。

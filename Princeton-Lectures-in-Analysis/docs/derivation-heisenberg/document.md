# 用分部积分、Cauchy–Schwarz 和 Plancherel证明测不准界

平移与调制先把  $x_0,\xi_0$  化为零。由归一化及快速衰减，分部积分得
 $1=-\int x(\psi'\overline\psi+\psi\overline{\psi'})$  ，故
 $1\le2\|x\psi\|_2\|\psi'\|_2$  。微分对偶与 Plancherel 给
 $\|\psi'\|_2^2=4\pi^2\|\xi\widehat\psi\|_2^2$  ，整理得常数  $1/(16\pi^2)$  。等号迫使  $\psi'=\beta x\psi$  ，Schwartz 条件选出高斯。

**认知成本：3.5/5**。跨越中心化、分部积分、等号条件和频率范数转换。**来源**：第一卷第 5 章 Theorem 4.1，书页 158–159（PDF 175–176）。

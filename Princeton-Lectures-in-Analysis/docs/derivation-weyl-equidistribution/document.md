# 用连续夹逼证明无理倍数等分布

区间命中比例正是 $N^{-1}\sum\chi_{(a,b)}(n\gamma)$ 。用 $f^-_\varepsilon\le\chi\le f^+_\varepsilon$ 夹住它，对两侧应用连续轨道平均；两积分分别落在 $b-a\pm2\varepsilon$ 内。于是命中比例的下极限和上极限也被夹住，令 $\varepsilon\downarrow0$ 得极限 $b-a$ 。

**认知成本：2.5/5**。难点是把不连续示性函数转成可用的连续夹逼。**来源**：第一卷第 4 章 Theorem 2.1，书页 108–110（PDF 125–127）。

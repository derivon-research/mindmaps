# 叠加分离频率块构造连续反例

选 $\alpha_k=k^{-2}$ 与增长极快、满足 $N_{k+1}>3N_k$ 的 $N_k$ 。平移频率块统一有界，故 $\sum\alpha_kP_{N_k}$ 一致收敛为连续函数。在截断 $2N_m$ 处，更低块已完整收入、更高块尚未进入，只有第 $m$ 块被不对称切开；其值为 $\alpha_m\log N_m$ 量级并趋于无穷，其他贡献保持有界。

平移块隔离坏行为，Abel 控制保证完整块统一有界，一致收敛保证最终函数连续。

# 高斯函数的 Fourier 自对偶

归一化高斯满足

$$\widehat G(\xi)=e^{-\pi\xi^2}=G(\xi).$$

令 $F=\widehat G$ 。由 $G'=-2\pi xG$ 及微分乘法对偶得到 $F'=-2\pi\xi F$ ；再用 $F(0)=\int G=1$ 解一阶常微分方程。伸缩律进一步给

$$\delta^{-1/2}e^{-\pi x^2/\delta}\longmapsto e^{-\pi\delta\xi^2}.$$

第二卷给出独立的复分析路线：把整函数 $e^{-\pi z^2}$ 的矩形围道向上或向下平移，竖边消失后直接识别 Fourier 积分。

**来源**：第一卷第 5 章 Theorem 1.4、Corollary 1.5，书页 138–139（PDF 155–156）；第二卷第 2 章 Example 1，书页 42–44（PDF 物理页 387–389）。

# 用方形围道求和余切极点

对固定 $z\notin\mathbb Z$ ，考察具有整数格点极点的函数

$$\frac{\pi\cot(\pi\zeta)}{\zeta^2-z^2}.$$

在边长避开整数的扩大方形上， $\cot(\pi\zeta)$ 有界，而分母给 $O(|\zeta|^{-2})$ ，故围道积分趋于零。留数公式把 $\zeta=\pm z$ 与所有整数极点的留数相加，整理得到

$$\pi\cot\pi z=\frac1z+\sum_{n=1}^{\infty}\frac{2z}{z^2-n^2}.$$

**认知成本：4/5**。难点是选择同时捕捉整数极点且边界估计稳定的方形围道。**来源**：第二卷第 5 章 §3.2，书页 142–143（PDF 487–488）。

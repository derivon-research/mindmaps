# Weyl 判别法

序列 $\{\xi_n\}\subset[0,1)$ 等分布，当且仅当对每个非零整数 $k$ ，

$$\frac1N\sum_{n=1}^Ne^{2\pi ik\xi_n}\longrightarrow0.$$

一个方向由指数函数、三角多项式逼近和示性函数夹逼得到；反方向先把等分布推广为连续函数的平均公式，再取复指数。它把分布问题归结为指数和估计。

练习与问题展示了判别法的分辨力： $\langle an^\sigma\rangle$ 对 $a\ne0$ 、非整数 $\sigma>0$ 等分布，而 $\langle a\log n\rangle$ 不等分布。证明都通过把离散指数和与相应振荡积分比较； $0<\sigma<1$ 时可得 $O(N^\sigma)+O(N^{1-\sigma})=o(N)$ 。

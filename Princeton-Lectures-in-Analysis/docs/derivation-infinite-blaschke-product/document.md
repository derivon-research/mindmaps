# 用 Blaschke 条件统一控制归一化因子

归一化因子

$$B_\alpha(z)=\frac{\alpha-z}{1-\overline\alpha z}\frac{|\alpha|}{\alpha}$$

在 $|z|\le r<1$ 上满足 $|1-B_\alpha(z)|\le C_r(1-|\alpha|)$ 。Blaschke 条件使这些误差可和，因此全纯无穷乘积定理给紧一致收敛及精确零点。每个有限部分积在圆盘内模不超过 $1$ ，极限也满足同一界。

**认知成本：3/5**。需找到与边界距离 $1-|\alpha|$ 成正比的统一误差估计。**来源**：第二卷第 5 章 Problem 2，书页 157（PDF 502）。

# 二变量 Jacobi Theta 函数

对 $z\in\mathbb C$ 、 $\tau\in\mathbb H$ ，定义

$$\Theta(z\mid\tau)=\sum_{n\in\mathbb Z}e^{\pi in^2\tau}e^{2\pi inz}.$$

它关于 $z$ 为整函数、关于 $\tau$ 为全纯函数；一变量特例为 $\theta(\tau)=\Theta(0\mid\tau)$ 与 $\vartheta(t)=\theta(it)$ 。

**来源**：第二卷第 10 章 §1 与 Proposition 1.1(i)，书页 283–285（PDF 628–630）。

# 矩形上的 Dirichlet 解

在 $0\le x\le\pi$ 、 $0\le y\le1$ 的矩形中，竖边温度为零，横边数据分别为 $f_0,f_1$ 。若

$$f_0=\sum_{k\ge1}A_k\sin kx,\qquad f_1=\sum_{k\ge1}B_k\sin kx,$$

则分离变量给出

$$u(x,y)=\sum_{k\ge1}\left[\frac{\sinh k(1-y)}{\sinh k}A_k+\frac{\sinh ky}{\sinh k}B_k\right]\sin kx.$$

这是章末问题给出的目标公式，完整推导留给读者；使用它仍需说明级数的收敛与可微性。

# 用 Poisson 求和重新计算 zeta 偶值

对上半平面 Poisson 核  $t/[\pi(x^2+t^2)]$  应用 Poisson 求和，得到有理格点和等于指数几何和。对  $0<t<1$  ，一边按  $t^2/n^2$  展开产生  $\zeta(2m)t^{2m-1}$  ，另一边写成  $2/(1-e^{-2\pi t})-1$  ；代入 Bernoulli 生成函数并比较幂次，得到
 $2\zeta(2m)=(-1)^{m+1}(2\pi)^{2m}B_{2m}/(2m)!$  。

**认知成本：3.5/5**。这是 Poisson 求和、两侧幂级数和系数比较组成的独立平行证明。**来源**：第一卷第 5 章练习 19，书页 166–167（PDF 183–184）。

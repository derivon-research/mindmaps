# 等周不等式

长度为 $\ell$ 的简单闭平面曲线所围面积满足

$$A\le\frac{\ell^2}{4\pi},$$

且等号成立当且仅当曲线是圆。归一化证明中的等号链迫使坐标函数只含常数项与第一频率；实值对称性和相位关系进一步把参数式化成

$$x=a_0+\cos(\alpha+s),\qquad y=b_0\pm\sin(\alpha+s).$$

练习 4 还表明，在本章采用的长度与线积分面积定义下，该不等式与 Wirtinger 不等式等价，并可放宽到非简单闭曲线。

**来源**：第一卷第 4 章 Theorem 1.1 与练习 4，书页 103–105、122（PDF 120–122、139）。

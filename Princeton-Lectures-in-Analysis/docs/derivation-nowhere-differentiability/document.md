# 以增长率矛盾排除每个可微点

假设  $f_\alpha$  在  $x_0$  可微。Fejér 导数界给
 $|\Delta_{2N}'(x_0)-\Delta_N'(x_0)|=O(\log N)$  。频块抽取后直接求导，同一量等于  $2^{n(1-\alpha)}$  ，其中  $2N=2^n$  ，因而至少为  $cN^{1-\alpha}$  。  $0<\alpha<1$  时正幂最终压过对数，矛盾。

**认知成本：3/5**。两个独立估计在同一抽取量上碰撞；中间估计均已拆点。**来源**：第一卷第 4 章 Theorem 3.1，书页 117–118（PDF 134–135）。

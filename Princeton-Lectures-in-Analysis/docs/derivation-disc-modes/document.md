# 分离圆盘调和方程得到模态

在极坐标拉普拉斯式中令 $u=F(r)G(\theta)$ ，得到角方程 $G''+\lambda G=0$ 与 Euler 型径向方程 $r^2F''+rF'-\lambda F=0$ 。角变量的 $2\pi$ 周期性要求 $\lambda=m^2$ 、 $m\in\mathbb Z$ ；径向解中舍去在 $r=0$ 无界的 $r^{-|m|}$ 与 $\log r$ ，保留 $r^{|m|}$ 。因此模态为 $r^{|m|}e^{im\theta}$ 。

调和性给出方程，极坐标公式使几何可分，圆盘问题提供周期与原点有界要求，分离变量组织两个 ODE。

**认知成本：3.5/5**。需处理周期谱、Euler 方程和正则性筛选。**来源**：书页 21–22；练习 11，书页 27（PDF 38–39、44）。

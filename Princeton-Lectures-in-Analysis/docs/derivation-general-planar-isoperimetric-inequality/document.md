# 一般平面等周不等式的推导

定义外集 $\Omega^+(\delta)=\{d(x,\Omega)<\delta\}$ 与内集 $\Omega^-(\delta)=\{d(x,\Omega^c)\ge\delta\}$ 。由 $\Omega+D(\delta)\subset\Omega^+(\delta)$ 、 $\Omega^-(\delta)+D(\delta)\subset\Omega$ 及 Brunn–Minkowski，分别得到外增量与内亏损的下界；再用不交分解 $\Omega^+(\delta)=\Omega^-(\delta)\cup\Gamma^\delta$ 相加，得 $m(\Gamma^\delta)/(2\delta)\ge\sqrt\pi(\sqrt{m(\Omega)}+\sqrt{m(\Omega^-(\delta))})$ 。令 $\delta\to0$ 时内集递增穷竭 $\Omega$ ，而可求长曲线的上 Minkowski 内容不超过 $L(\Gamma)$ ，故 $L(\Gamma)\ge2\sqrt{\pi m(\Omega)}$ 。

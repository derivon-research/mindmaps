# 优化衰减指数与复振荡增长

参数积分在紧集上受可积函数控制，故定义整函数。其模满足

$$
|F_\alpha(z)|\le\int_{\mathbb R}
e^{-|t|^\alpha+2\pi|z||t|}\,dt.
$$

Young 型优化给  $-|t|^\alpha+2\pi|z||t|\le C|z|^{\alpha/(\alpha-1)}-c|t|^\alpha$  ，得到相应阶上界；沿纯虚方向在最优  $|t|\asymp|z|^{1/(\alpha-1)}$  附近积分给匹配下界。

**认知成本：2.5/5**。增长阶由一维凸优化的共轭指数决定。**来源**：第二卷第 5 章 Exercise 5，书页 154（PDF 499）。

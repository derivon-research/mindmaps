# 以典范乘积剥离零点并控制剩余指数

取 $k\le\rho<k+1$ 。零点指数收敛保证固定亏格乘积

$$E(z)=z^m\prod_nE_k(z/a_n)$$

为整函数并具有与 $f$ 相同的零点。故 $f/E$ 整且不消失，可写为 $e^g$ 。在良好圆周上， $f$ 的增长上界与 $E$ 的下界合并给

$$\operatorname{Re}g(z)=\log|f(z)/E(z)|\le C|z|^s$$

其中 $\rho<s<k+1$ 。实部增长判据迫使 $g$ 为次数至多 $k$ 的多项式，得到分解。

**认知成本：4.5/5**。这是本章主桥梁：既要精确实现零点，又要用稀疏圆周下界控制无零商。**来源**：第二卷第 5 章 Theorem 5.1，书页 147–153（PDF 492–498）。

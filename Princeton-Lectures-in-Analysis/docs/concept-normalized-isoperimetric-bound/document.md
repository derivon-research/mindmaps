# 归一化等周上界

若简单闭曲线以弧长参数化在 $[0,2\pi]$ ，则

$$A\le\pi.$$

令坐标函数的傅里叶系数为 $a_n,b_n$ 。弧长条件与 Parseval 给

$$\sum_n n^2(|a_n|^2+|b_n|^2)=1,$$

面积的极化 Parseval 表达再结合
$|a_n\overline{b_n}-b_n\overline{a_n}|\le |a_n|^2+|b_n|^2$ 与 $|n|\le n^2$ 得到上界。等号迫使所有 $|n|\ge2$ 的模态消失。

**来源**：第一卷第 4 章 Theorem 1.1 的归一化证明，书页 103–105（PDF 120–122）。

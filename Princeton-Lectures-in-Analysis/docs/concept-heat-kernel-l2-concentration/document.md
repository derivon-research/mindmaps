# 热核的平方质量集中

当 $t\downarrow0$ 时，圆周热核满足

$$\int_{-1/2}^{1/2}|H_t(x)|^2dx\asymp t^{-1/2},$$

更精确地，乘以 $t^{1/2}$ 后趋于非零极限；同时

$$\int_{-1/2}^{1/2}x^2|H_t(x)|^2dx=O(t^{1/2}).$$

第一式由 Parseval 把积分化为高斯和并与高斯积分比较；第二式用 $x^2\le C\sin^2(\pi x)$ 和高斯系数的相邻差估计。它量化了热核在零点附近变尖，但本身尚不足以证明好核的 $L^1$ 条件或正性。

**来源**：第一卷第 4 章练习 13，书页 124–125（PDF 141–142）。

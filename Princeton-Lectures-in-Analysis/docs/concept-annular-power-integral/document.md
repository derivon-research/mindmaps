# 环域上幂函数的积分

对环域  $A(R_1,R_2)=\{R_1\le|x|\le R_2\}$  ，球坐标给出

$$
\int_{A(R_1,R_2)}|x|^\lambda\,dx=
\begin{cases}
\dfrac{\omega_d}{\lambda+d}(R_2^{\lambda+d}-R_1^{\lambda+d}),&\lambda\ne-d,\\
\omega_d(\log R_2-\log R_1),&\lambda=-d.
\end{cases}
$$

取  $\lambda=-d-1$  时，外部壳层尾积分按  $R_1^{-1}$  衰减。

**来源**：第一卷积分附录 §2.4，书页 293–294（PDF 310–311）。

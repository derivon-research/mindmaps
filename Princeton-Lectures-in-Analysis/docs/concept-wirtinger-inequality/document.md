# Wirtinger 不等式

若 $f$ 是 $T$ 周期、连续、分段 $C^1$ 且平均值为零，则

$$\int_0^T|f|^2\le\frac{T^2}{4\pi^2}\int_0^T|f'|^2.$$

等号只对第一频率的正弦余弦线性组合成立。它把去掉常数模态后的函数大小控制在导数能量之下。

第四章练习 4 说明：在闭曲线长度和定向线积分面积的定义下，Wirtinger 不等式与等周不等式等价。因而它不仅是函数空间中的谱隙估计，也能直接控制平面曲线围成的面积。

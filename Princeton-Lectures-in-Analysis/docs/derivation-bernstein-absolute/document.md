# 用二进频率块证明 Bernstein 定理

对增量 $g_h(x)=f(x+h)-f(x-h)$ 应用 Parseval，得到加权平方和 $\sum|\sin(nh)|^2|\widehat f(n)|^2$ 。取 $h=\pi/2^{p+1}$ ，在频率块 $2^{p-1}<|n|\le2^p$ 上正弦权重有统一下界；Hölder 条件给该块平方和 $O(2^{-2\alpha p})$ 。Cauchy–Schwarz再乘块大小的平方根，绝对和块为 $O(2^{(1/2-\alpha)p})$ ，在 $\alpha>1/2$ 时可求和。

**认知成本：4/5**。关键是频率分块与两个范数间的转换。**来源**：练习 16，书页 92–93（PDF 109–110）。

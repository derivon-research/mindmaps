# 疏傅里叶级数

若傅里叶级数只在彼此快速分离的频率上有非零系数，称为疏傅里叶级数。典型频率是 $2^n$ ：相邻频率成固定倍数增长，中间留下越来越宽的零系数区间。

这种频谱空隙使特制的求和算子能单独抽取一个频块；本章利用这一点把“假设某点可微”转化为相互矛盾的增长估计。

历史上，Riemann 猜测 $\sum_{n\ge1}\sin(n^2x)/n^2$ 处处不可微，但后来发现它在某些有理倍数 $\pi p/q$ 处可微。Weierstrass 则用 $\sum b^n\cos(a^nx)$ 给出首个连续处处不可微例子。二进函数 $f_\alpha$ 把同类现象化成特别清楚的频块论证。

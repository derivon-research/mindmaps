# 连续函数的积分逼近

若圆周上的 Riemann 可积函数 $f$ 由 $B$ 控制，则存在连续函数列 $f_k$ ，满足 $\sup|f_k|\le B$ 且

$$\int_{-\pi}^{\pi}|f-f_k|\longrightarrow0.$$

该引理允许先对连续函数合法地换序、换元，再把卷积结论传回一般可积函数。附录中的证明先用分割上确界构造阶梯函数 $f^*$ ，再在各跳点附近作周期线性连接；两次积分误差分别压到任意小，最后用三角不等式合并。

**来源**：第 2 章 Lemma 3.2，书页 47（PDF 64）；积分附录 Lemma 1.5，书页 285–286（PDF 302–303）。

# Schwartz 空间上的 Fourier 双射

定义逆变换

$$\mathcal F^*g(x)=\int_{\mathbb R}g(\xi)e^{2\pi ix\xi}\,d\xi.$$

Fourier 反演给 $\mathcal F^*\mathcal F=I$ ；符号反射又给 $\mathcal F\mathcal F^*=I$ 。因此 Fourier 变换是 $\mathcal S(\mathbb R)$ 到自身的双射，且 $\mathcal F^2f(x)=f(-x)$ 、 $\mathcal F^4=I$ 。

**来源**：第一卷第 5 章 Corollary 1.10、练习 6，书页 141–142、163（PDF 158–159、180）。

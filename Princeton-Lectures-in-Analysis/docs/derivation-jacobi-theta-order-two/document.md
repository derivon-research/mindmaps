# 平衡高斯序号衰减与线性指数增长

令 $t=\operatorname{Im}\tau>0$ 。第 $n$ 项的模不超过

$$e^{-\pi n^2t+2\pi|n||z|}.$$

把 $|n|\le C|z|$ 的有限段粗略控制，把尾段用 $-n^2t+2n|z|\le-n^2t/2$ 控制，得到 $|\Theta(z\mid\tau)|\le Ae^{B|z|^2}$ 。结合 theta 的准周期增长或适当方向的下界，排除小于 $2$ 的阶。

**认知成本：2.5/5**。核心是按序号与 $|z|$ 的相对尺度分段。**来源**：第二卷第 5 章 Exercise 3，书页 153（PDF 498）。

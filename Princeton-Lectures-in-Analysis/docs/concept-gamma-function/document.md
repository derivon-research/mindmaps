# Gamma 函数

对 $s>0$ ，Gamma 函数定义为

$$\Gamma(s)=\int_0^\infty e^{-t}t^{s-1}dt.$$

原点附近由 $s>0$ 保证可积，无穷远由指数衰减控制。分部积分给 $\Gamma(s+1)=s\Gamma(s)$ ，所以 $\Gamma(n+1)=n!$ ；高斯积分给 $\Gamma(1/2)=\sqrt\pi$ 。

**来源**：第一卷第 5 章练习 17，书页 165–166（PDF 182–183）。

第二卷第六章证明该积分在 $\operatorname{Re}s>0$ 定义全纯函数，并以递推、反射、典范乘积和 Mellin 变换系统研究其全平面结构。

**补充来源**：第二卷第 6 章 §1，书页 160–168（PDF 物理页 505–513）。

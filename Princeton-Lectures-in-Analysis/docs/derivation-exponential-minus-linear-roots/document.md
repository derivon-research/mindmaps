# 假设有限零点并比较 Hadamard 形式

函数 $F(z)=e^z-z$ 的阶至多 $1$ 。若它只有有限个零点，Hadamard 定理给

$$F(z)=e^{az+b}P(z)$$

其中 $P$ 为多项式。沿正实轴 $x\to+\infty$ 比较 $F(x)\sim e^x$ ，迫使 $\operatorname{Re}a=1$ ；但沿负实轴 $x\to-\infty$ ，左端满足 $F(x)\sim-x$ ，右端的模却按 $e^x|P(x)|$ 衰减到 $0$ ，矛盾。因此零点必为无穷多。

**认知成本：3/5**。需要选择负实轴渐近来排除有限零点所强迫的指数多项式形式。**来源**：第二卷第 5 章 Exercise 13，书页 155（PDF 500）。

# 从长区间 Fourier 级数取极限

若  $f$  紧支撑于  $[-M,M]$  ，在  $[-L/2,L/2]$  展开时系数为  $L^{-1}\widehat f(n/L)$  。令  $\delta=1/L$  ，级数写成
 $\delta\sum_n\widehat f(n\delta)e^{2\pi in\delta x}$  ；适度衰减使它成为全实线积分的 Riemann 和，  $\delta\downarrow0$  即得反演。

**认知成本：3.5/5**。需同时控制无穷尾部和紧区间 Riemann 和；这是与高斯证明独立的平行路线。**来源**：第一卷第 5 章练习 1，书页 161–162（PDF 178–179）。

# 余切函数的部分分式展开

对 $u\notin\pi\mathbb Z$ ，

$$\cot u=\frac1u+2\sum_{n=1}^{\infty}\frac{u}{u^2-n^2\pi^2}.$$

本章先计算非整数 $\alpha$ 时 $\cos(\alpha x)$ 的傅里叶级数，再令 $x$ 取适当值并设置 $u=\pi\alpha$ ，得到该展开。它把余切的极点位置显式表示为整数格点。

**来源**：第 3 章，问题 3(a)–(b)，书页 96（PDF 113）。

第二卷第五章给出一条独立的复分析路线：对带有整数格点极点的 $\pi\cot(\pi\zeta)/(\zeta^2-z^2)$ 在扩大方形上应用留数公式，边界积分趋于零，直接得到同一展开。该路线随后通过对数导数积分导出正弦 Euler 乘积。

**补充来源**：第二卷第 5 章 §3.2，书页 142–145（PDF 物理页 487–490）。

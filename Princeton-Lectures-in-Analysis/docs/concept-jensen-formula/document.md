# Jensen 公式

设 $f$ 在包含 $\overline{D_R}$ 的开集上全纯， $f(0)\ne0$ ，且在 $|z|=R$ 上不消失。若 $z_1,\ldots,z_N$ 是 $D_R$ 内按重数列出的零点，则

$$
\log|f(0)|=\sum_{k=1}^N\log\frac{|z_k|}{R}
+\frac1{2\pi}\int_0^{2\pi}\log|f(Re^{i\theta})|\,d\theta.
$$

它精确平衡圆内零点的径向位置、中心函数值与边界对数模平均，是整函数零点分布的起点。

**来源**：第二卷第 5 章 Theorem 1.1，书页 135–137（PDF 物理页 480–482）。

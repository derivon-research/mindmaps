# 参数化平面曲线

参数化曲线是一个映射

$$\gamma:[a,b]\to\mathbb R^2,\qquad \gamma(s)=(x(s),y(s)).$$

其像集称为平面曲线。本文讨论的曲线通常为 $C^1$ 且 $\gamma'(s)\ne0$ ，因此每点都有连续变化的切向；参数从 $a$ 到 $b$ 的行进方向还给出曲线的定向。单调 $C^1$ 换元会改变参数而不改变几何曲线。

第二卷把同一对象写成 $z:[a,b]\to\mathbb C$ ，并区分几何曲线、参数化与定向；正导数的 $C^1$ 双射参数变换保持曲线不变。

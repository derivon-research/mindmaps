# 用 Phragmén–Lindelöf 把双高斯界逼成等号情形

先分解偶部与奇部。偶部的 Fourier 变换整且为偶函数，令 $g(z)=\widehat f(z^{1/2})$ ，在扇形中乘适当指数并应用广义 Phragmén–Lindelöf，极限得到 $e^{\pi z}g(z)$ 在全平面有界；Liouville 定理识别为高斯。奇部除以 $z$ 后同理只能为零，再合并两部分。

**认知成本：4.5/5**。跨越整延拓、平方根换元、扇形极限、奇偶分解与 Liouville。**来源**：第二卷第 4 章 Exercise 12，书页 130–131（PDF 475–476）。

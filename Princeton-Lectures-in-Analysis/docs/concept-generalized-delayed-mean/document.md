# 广义延迟平均

对傅里叶部分和定义

$$\sigma_{N,K}=\frac{S_N+\cdots+S_{N+K-1}}K.$$

它统一包含 $\sigma_{0,N}=\sigma_N$ 、 $\sigma_{N,1}=S_N$ 与 $\sigma_{N,N}=\Delta_N$ ，并满足

$$\sigma_{N,K}=\frac{(N+K)\sigma_{N+K}-N\sigma_N}{K}.$$

其频率表达只在 $N<|\nu|<N+K$ 留下线性过渡带，因此能定量比较 $\sigma_{N,K}$ 与同一区间内的任意部分和 $S_M$ 。

**来源**：第一卷第 4 章问题 5(a)，书页 127–128（PDF 144–145）。

# 从指数模态推广到连续轨道平均

对 $k\ne0$ ，无理性保证 $e^{2\pi ik\gamma}\ne1$ ，有限几何级数给

$$\frac1N\sum_{n=1}^Ne^{2\pi ikn\gamma}=O(1/N)\to0.$$

常数模态给积分平均；线性组合推广到所有三角多项式。最后对连续周期 $f$ 取一致逼近多项式 $P$ ，把轨道和误差、 $P$ 的极限误差和积分误差各控制在 $\varepsilon/3$ 内。

**认知成本：3/5**。包含指数计算、线性推广和一致逼近三步。**来源**：第一卷第 4 章 Lemma 2.2，书页 108–109（PDF 125–126）。

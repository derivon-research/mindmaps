# Riemann zeta 函数的偶整数值

对正整数 $m$ ，

$$2\zeta(2m)=(-1)^{m+1}\frac{(2\pi)^{2m}}{(2m)!}B_{2m}.$$

该公式把 $\sum_{n\ge1}n^{-2m}$ 精确表示为 $\pi^{2m}$ 与 Bernoulli 数的组合。本章通过 $z\cot z$ 的生成函数展开和余切部分分式展开比较系数得到。

第五章练习 19 给出独立的 Poisson 求和证明：将求和公式用于上半平面 Poisson 核，一边展开有理格点和而出现 $\zeta(2m)$ ，另一边展开指数几何和并代入 Bernoulli 生成函数；比较同次幂系数得到同一公式。

第二卷第六章 Problem 4 还从小数部分的周期原函数出发，识别其为 Bernoulli 多项式并再次得到该公式。

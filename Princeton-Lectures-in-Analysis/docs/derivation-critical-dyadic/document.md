# 用光滑截断和 Poisson 求和处理临界疏级数

选 $\Phi=1$ 于 $[-1,1]$ 、支撑于 $[-2,2]$ ，令 $\widehat\varphi=\Phi$ 并周期化 $N\varphi(Nx)$ 。Poisson 求和把该核精确写成乘子 $\Phi(n/N)$ 的有限三角多项式，因此在二进频谱上保留部分和。Schwartz 衰减给导数核的近区/远区估计，使它在假设可微点处卷积趋于真实导数；相邻二进模态的固定振幅却阻止该极限，实部和虚部均矛盾。

**认知成本：4/5**。高成本来自光滑频率截断、周期化核估计和临界尺度极限；Poisson 求和与第 4 章延迟平均已拆为中间点。**来源**：第一卷第 5 章问题 8，书页 174（PDF 191）。

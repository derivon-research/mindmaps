# 定向面积线积分

对简单闭曲线  $\Gamma$  ，本章以

$$
A=\frac12\left|\int_\Gamma(x\,dy-y\,dx)\right|
=\frac12\left|\int_a^b(xy'-yx')\,ds\right|
$$

定义所围区域的面积。反转定向会改变积分符号但不改变绝对面积；利用闭曲线上的分部积分，还可在适当定向下写成  $A=\int_a^bxy'\,ds=-\int_a^byx'\,ds$  。

**边界**：本章未从一般几何面积定义证明此公式，只在可分成上下图像的区域中由练习 3 核对。

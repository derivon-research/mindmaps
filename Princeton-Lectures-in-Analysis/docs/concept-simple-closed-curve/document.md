# 简单闭曲线

参数化曲线 $\gamma:[a,b]\to\mathbb R^2$ 称为闭曲线，若 $\gamma(a)=\gamma(b)$ ；称为简单曲线，若除此端点重合外没有自交： $\gamma(s_1)\ne\gamma(s_2)$ 。

闭参数化可周期延拓，因此也可视为圆周上的向量值函数。简单闭曲线围成区域这一几何事实很深；本章为快速证明等周不等式，直接用线积分规定面积而不处理 Jordan 曲线定理等基础问题。

第二卷沿用同一定义：闭曲线允许首尾参数代表同一点，除此之外无自交时才称简单。

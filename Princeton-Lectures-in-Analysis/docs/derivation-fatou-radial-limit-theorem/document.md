# Fatou 径向极限定理的第三卷推导

写 $F(z)=\sum_{n\ge0}a_nz^n$ 。对每个 $r<1$ ，Parseval 给 $\sum|a_n|^2r^{2n}=(2\pi)^{-1}\int|F(re^{i\theta})|^2d\theta\le M^2$ ；令 $r\uparrow1$ 得 $\{a_n\}\in\ell^2$ 。酉 Fourier 定理产生边界 $L^2$ 函数，Abel 几乎处处收敛恰给 $F(re^{i\theta})$ 的径向极限。

**认知成本：4/5**。**来源**：第三卷第 4 章，书页 173–174（PDF 物理页 173–174）。

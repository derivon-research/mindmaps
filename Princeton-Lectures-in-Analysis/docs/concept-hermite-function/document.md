# Hermite 函数

Hermite 函数由生成式

$$
\sum_{k=0}^\infty h_k(x)\frac{t^k}{k!}
=e^{-(x^2/2-2tx+t^2)}
$$

定义，也可写为  $h_k(x)=(-1)^ke^{x^2/2}(d/dx)^ke^{-x^2}$  。因此  $h_k=P_k(x)e^{-x^2/2}$  ，属于 Schwartz 空间。它们在  $L^2$  中两两正交，并满足 Hermite 算子本征方程  $Lh_k=(2k+1)h_k$  。

**来源**：第一卷第 5 章问题 7(a)、(d)–(e)，书页 173–174（PDF 190–191）。

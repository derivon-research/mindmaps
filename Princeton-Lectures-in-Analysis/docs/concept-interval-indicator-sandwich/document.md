# 区间示性函数的连续夹逼

区间 $(a,b)$ 的周期示性函数不连续，不能直接代入连续轨道平均。对任意 $\varepsilon>0$ ，可构造连续周期函数 $f^-_\varepsilon,f^+_\varepsilon$ ，使

$$f^-_\varepsilon\le\chi_{(a,b)}\le f^+_\varepsilon,$$

且二者只在端点附近总长度 $2\varepsilon$ 的区域偏离示性函数，积分误差至多 $2\varepsilon$ 。上下极限夹逼随后允许 $\varepsilon\downarrow0$ 。

**来源**：第一卷第 4 章 Theorem 2.1 的证明，书页 109–110（PDF 126–127）。

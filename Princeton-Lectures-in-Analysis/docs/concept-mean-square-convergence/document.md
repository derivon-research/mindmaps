# 均方收敛

在圆周上， $S_N(f)$ 均方收敛到 $f$ 是指

$$\frac1{2\pi}\int_{-\pi}^{\pi}|S_N(f)(\theta)-f(\theta)|^2\,d\theta\longrightarrow0.$$

第三章证明：对每个圆周 Riemann 可积函数，上式确实成立。它是全局积分意义的收敛，不保证任一固定点上的部分和收敛；练习 3 甚至构造均方趋零但每一点都不逐点收敛的函数列。

**来源**：第 2 章，书页 39（PDF 56）；第 3 章，Theorem 1.1/1.3，书页 69–80，练习 3，书页 88（PDF 86–97、105）。

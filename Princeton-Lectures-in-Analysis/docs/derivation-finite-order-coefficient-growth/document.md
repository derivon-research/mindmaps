# 优化 Cauchy 半径并反向比较阶乘级数

若 $|F(z)|\le Ae^{ar^\rho}$ ，Cauchy 不等式给

$$|a_n|\le A r^{-n}e^{ar^\rho}.$$

对 $r$ 优化，即取 $r^\rho\asymp n$ ，得到 $|a_n|^{1/n}n^{1/\rho}=O(1)$ 。反之，该系数界给 $|a_n|\le c^n n^{-n/\rho}\le c^n/(n!)^{1/\rho}$ ；与阶乘幂级数比较，得到任意略大于 $\rho$ 的指数增长界。

**认知成本：3.5/5**。同一尺度需在 Cauchy 优化和级数比较两个方向精确匹配。**来源**：第二卷第 5 章 Problem 4，书页 157–158（PDF 502–503）。

# 圆盘 Blaschke 因子

固定 $w\in\mathbb D$ ，映射

$$F_w(z)=\frac{w-z}{1-\overline wz}$$

全纯地把单位圆盘双射到自身，交换 $0$ 与 $w$ ，并在 $|z|=1$ 上满足 $|F_w(z)|=1$ 。本章习题还验证 $F_w\circ F_w$ 为恒等映射。

第三章用这一自同构把调和函数在圆心的平均值公式搬到任意内点，Jacobian 因子由此产生 Poisson 核。

**来源**：第二卷第 1 章 Exercise 7，书页 26–27（PDF 物理页 371–372）；第二卷第 3 章 Problem 2，书页 109（PDF 物理页 454）。

第五章把它用于零点分布：有限个因子的乘积可在 Jensen 公式中剥离圆盘零点；归一化因子

$$\frac{\alpha-z}{1-\overline\alpha z}\frac{|\alpha|}{\alpha}$$

在 $\sum(1-|\alpha_n|)<\infty$ 时还能组成有界的无穷 Blaschke 乘积。

**补充来源**：第二卷第 5 章 Exercise 1 与 Problems 1–2，书页 153、156–157（PDF 物理页 498、501–502）。

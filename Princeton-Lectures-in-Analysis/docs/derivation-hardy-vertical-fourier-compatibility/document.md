# Hardy 水平线 Fourier 数据的高度相容性的第三卷推导

先乘 $(1-i\varepsilon z)^{-2}$ 得到在真子半平面沿 $x$ 为 $O((1+x^2)^{-1})$ 的 $F^\varepsilon$ 。对 $F^\varepsilon(z)e^{-2\pi iz\xi}$ 沿两条水平线围成的矩形积分，竖边在 $R\to\infty$ 时消失，给出高度相容式；再令 $\varepsilon\to0$ ，水平线函数在 $L^2$ 中收敛，传递等式。

**认知成本：4/5**。**来源**：第三卷第 5 章，书页 214–217（PDF 物理页 214–217）。

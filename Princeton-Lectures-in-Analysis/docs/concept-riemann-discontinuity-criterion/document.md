# Riemann 可积性的零测不连续点判别

闭区间上的有界函数 Riemann 可积，当且仅当它的不连续点集是零测集。

正向：用紧集 $A_\varepsilon$ 的有限小长度覆盖处理大振荡处，在补集上取有限个小振荡邻域，得到 $U-L\le C\varepsilon$ 。反向：若 $U(P,f)-L(P,f)<\varepsilon/n$ ，所有与 $A_{1/n}$ 相交的分割区间总长度小于 $\varepsilon$ ；再用不连续集 $D=\bigcup_n A_{1/n}$ 与可数并引理完成。

**来源**：第一卷积分附录 Theorem 1.7，书页 287–289（PDF 304–306）。

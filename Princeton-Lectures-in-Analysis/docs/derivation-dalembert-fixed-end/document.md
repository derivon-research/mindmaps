# 从初始数据得到固定端 d'Alembert 公式

整线分解给 $u=F(x+t)+G(x-t)$ 。在 $t=0$ 代入位置与速度，得

$$F+G=f,\qquad F'-G'=g.$$

相加、相减并积分求出 $F,G$ ，消去积分常数后得到 d'Alembert 公式。对 $[0,\pi]$ 固定端弦，把 $f,g$ 作奇的 $2\pi$ 周期延拓；奇性保证 $x=0$ 处为零，周期性结合奇性保证 $x=\pi$ 处也为零。

四个尾点分别提供一般整线形式、确定两函数的两项数据、实现端点的延拓机制和必须满足的边界目标。

**认知成本：3/5**。核心是联立函数方程并看出奇周期延拓如何编码边界。**来源**：书页 10–11（PDF 27–28）。

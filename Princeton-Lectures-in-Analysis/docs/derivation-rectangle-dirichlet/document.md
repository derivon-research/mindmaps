# 用分离变量构造矩形 Dirichlet 解

竖边为零使空间方向采用 $\sin(kx)$ 。对每个 $k$ ，调和方程令纵向因子满足 $Y''-k^2Y=0$ ；用在 $y=0$ 取 1、在 $y=1$ 取 0 的 $\sinh(k(1-y))/\sinh k$ 传递下边界系数，用相反的 $\sinh(ky)/\sinh k$ 传递上边界系数。叠加所有正弦频率得到文档中的公式。

调和函数规定 PDE，分离变量给单频结构，正弦系数承载横边数据。严格交换求和与求导仍需收敛条件。

**认知成本：4/5**。章末问题要求读者独立选择双曲函数并同时匹配四条边。**来源**：问题 1，书页 28（PDF 45）。

# 直接证明这条路作废之后，改从否定入手

**问题压力（逻辑；萨凯里本人的动机见下）**：等价性诊断堵死了原来的纲领。只要还想从「更基本的前提」推出第五公设，就会掉进同一个陷阱：任何足够强、能推出它的前提，都被证明与它等价，于是并不更基本。这不是运气不好，这是结构性的。继续找下去没有出路。

**解决动作**：换一个方向——不再补充前提，而是**减去**一条。把第五公设从清单里拿掉，代之以它的否定，然后在剩下的公设加上这条否定之下尽量往前推。如果这个体系是不相容的，矛盾迟早会出现；矛盾一出现，反证法立刻把第五公设变成定理。这条路完全不需要新前提，因此等价性诊断对它无效。

萨凯里在 1733 年把这个方向做成了可执行的形式。他构造一个底角为直角、两腰等长的四边形，证明其余两个顶角必定相等，于是全部可能性被穷尽为三种：顶角是直角、是钝角、是锐角。直角情形等价于第五公设本身，剩下要做的就是把钝角与锐角两种情形分别推到矛盾。穷尽性是这个设计的要害：三种情形之外没有第四种，堵住两条就等于证完。

这一步只用到一个前提。正是「所有尝试都只是等价替换」这个诊断，才使得放弃寻找更基本前提成为一个有理由的决定，而不是随意换招。

## 来源与范围

Girolamo Saccheri, *Euclides ab omni naevo vindicatus*（米兰，1733）；De Risi 编注本 *Euclid Vindicated from Every Blemish*（Springer, 2014）导论关于该书目标的说明；早稻田大学 MI314 讲义关于萨凯里四边形与三假设的整理。

必须保留的不确定性：萨凯里自己的动机不是本文重构的这条逻辑。他的目标是捍卫欧几里得，书名就是「欧几里得免于一切瑕疵」，他相信矛盾必定存在。把「等价性诊断迫使方向转换」写成问题压力，是本图为串起链条所作的逻辑重构，不是萨凯里的自述。

## 权重理由

权重 2.5，暂定值。反证法本身是学习者熟悉的工具，这里没有新技术。成本主要在两处：看出等价性诊断为什么能逼出方向转换，以及理解穷尽三种情形为什么足以完成证明。这接近一次常规组合加一个不算显然的观察。该值尚未由学习者的实际用时校准，属于 provisional。

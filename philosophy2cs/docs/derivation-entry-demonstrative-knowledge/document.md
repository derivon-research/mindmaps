# 入口：为什么这条主线从"什么算认识"开始

这条主线要追问的是：数学与计算里那些被当作起点的东西，凭什么被当作起点。要回答它，必须先有一个不依赖任何图内前提的落脚点。

**问题压力（教学性，本文为重构）**：学习者通常已经会做证明，却很少被问过"证明到底为知识提供了什么"。如果不先固定这个问题，后面关于公理、公设、形式系统、可计算性的所有讨论都缺少共同的判据。工科教学从二进制和门电路自底向上讲起时，绕过的正是这个问题。

**解决动作**：引入亚里士多德在《后分析篇》中对"[论证性知识](../concept-demonstrative-knowledge/index.html)"的刻画，把"认识一个命题"定义为"从更为人所知、并且解释它的前提中推出它"。这个刻画只需要日常的推理经验就能理解，不需要图中的其他概念，因此它是一个真实的无尾入口，而不是人为的起点。

## 来源与范围

亚里士多德《后分析篇》I.2；SEP "Aristotle's Logic" 关于 demonstration 的一节。

## 权重理由

权重 1.0，暂定值。理解这一步只需把日常的"证明"经验替换成一个更严格的说法，没有方法选择，也没有需要构造的论证。该值尚未由学习者的实际用时校准，属于 provisional。

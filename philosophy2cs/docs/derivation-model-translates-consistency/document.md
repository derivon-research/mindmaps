# 把新几何翻译进旧几何，用有限的构造代替无限的搜索

**问题压力（历史与逻辑）**：非欧几何已经被建设成一门有内容的学科，但它的地位仍然悬空。反对者的问题很简单也很致命：你们只是还没找到矛盾。这个反驳无法用继续推演来回答，因为推演是无穷的，任何有限的推进都可以被说成推得不够远。罗巴切夫斯基与波尔约拿不出证据结束这场争论。更麻烦的是，这个反驳与「锐角假设违反空间直觉」的印象互相加强：既然它看起来不像真的，那它多半在某处藏着矛盾。

**解决动作**：不再搜索矛盾，改为**建造一个翻译**。贝尔特拉米在欧氏空间内部找到具体对象来充当非欧几何的术语——常负曲率曲面上的点当作「点」，曲面上的测地线当作「直线」，曲面上的度量当作「距离」；在射影解释中则用圆盘内部的点当作「点」、圆盘的弦当作「直线」。然后逐条验证非欧几何的每一条公理在这套指派下都变成欧氏几何中已经成立的命题。

验证完成，翻译就生效了，而且它的作用范围是全部证明而不是某个证明。设想非欧几何里存在一条通向矛盾的证明，把它逐句翻译过去，就得到欧氏几何里一条通向矛盾的证明。于是结论成立：如果欧氏几何不含矛盾，非欧几何也不含矛盾。

这一步的分量在于它改变了问题的**类型**。原来的任务是在无限多条可能的证明里搜寻一个矛盾，永远无法宣告完成；现在的任务是造出一个指派并验证有限条公理，可以当场做完。两千年的搜索被一次构造取代，而这个构造给出的答案是搜索本身永远给不出的：那个矛盾不存在。

两个前提缺一不可。没有被建设成完整学科的非欧几何，就没有需要被翻译的公理体系，也没有值得回答的地位问题。没有欧几里得的演绎体系，就没有可以接收翻译的靶子——曲面、测地线、圆盘、弦这些对象全都住在欧氏几何里，「相对相容」也就相对无所依。

## 来源与范围

Eugenio Beltrami, *Saggio di interpretazione della geometria non-euclidea*（1868）；同作者 *Teoria fondamentale degli spazii di curvatura costante*（1868–69）；MacTutor 关于贝尔特拉米率先以常曲率曲面建模确立相容性的说明；Wikipedia "Beltrami–Klein model" 关于该模型的出处与克莱因 1871 年独立构造的说明。

必须保留的不确定性：本条对翻译论证的表述采用现代形式。贝尔特拉米使用的语言是微分几何的解释，而不是公理与模型的元数学语言；把它整理成「相对相容性证明」是希尔伯特之后的标准化读法。此外伪球面只在局部实现双曲平面，整体情形由第二篇论文与射影模型处理，本条不展开技术细节。

## 权重理由

权重 4.0，暂定值。这是本段的核心技术，也是全图到此为止最需要引导的一步。学习者要接受几何术语可以被**重新指派**给别的对象而不损害推理，要看出验证有限条公理为什么能覆盖无限多条证明，还要理解结论为什么只能是相对的。这三点各自都不显然，合起来构成一个关键技术。该值尚未由学习者的实际用时校准，属于 provisional。

# 萨凯里纲领：假设第五公设为假，推到矛盾为止

这是一套研究方法：不再寻找比第五公设更基本的前提，而是假设它为假，然后在这个假设下大量推演，期待推出矛盾。矛盾一旦出现，反证法就把第五公设确立为定理。

萨凯里在 1733 年的《Euclides ab omni naevo vindicatus》（欧几里得免于一切瑕疵）中执行了这个纲领。他的工具是一个四边形：底边两端各竖一条等长的边，且都与底边垂直。剩下的两个顶角必然彼此相等，于是穷尽的情形只有三种。

- **直角假设**：两个顶角都是直角。这等价于第五公设。
- **钝角假设**：两个顶角都是钝角。
- **锐角假设**：两个顶角都是锐角。

只要能把钝角和锐角两种情形都推到矛盾，第五公设就被证明了。

## 边界

这个纲领与前人的尝试有本质区别，值得说清楚。前人是在找**更基本的前提**，因此总是掉进等价替换的陷阱。萨凯里换了方向：他不需要任何新前提，只需要否定命题和其余公设，让矛盾自己浮出来。这条路不受等价性诊断的影响。

要注意萨凯里的意图。他的书名是「欧几里得免于一切瑕疵」，他要做的是**捍卫**欧几里得，不是推翻他。他从头到尾相信矛盾一定存在。

这个纲领的形式在后面会反复出现：假设否定、大量推演、看会得到什么。当它推不出矛盾时，同一套推演就变成了别的东西。

## 来源与范围

Girolamo Saccheri, *Euclides ab omni naevo vindicatus*（米兰，1733）；De Risi 编注、Halsted 与 Allegri 英译的 *Euclid Vindicated from Every Blemish*（Springer, 2014）；早稻田大学 MI314 讲义中关于萨凯里四边形与三个假设的整理。

# 每次证明平行公设的尝试都换入了一条等价假设

这是对两千年失败的诊断结论：那些「证明」并没有把第五公设推出来，它们只是把它换成了另一个说法。每份证明里都有一步用到了一条未经声明的假设，而那条假设在其余公设之下与第五公设**等价**。等价意味着由它推出第五公设是合法的，但也意味着它本身同样不可证明，于是什么都没被消除。

## 已知的等价命题

这些命题各自看起来比第五公设更顺眼，这正是它们能蒙混过关的原因。

- **普莱费尔公理**：过直线外一点，至多有一条直线与之平行。
- **三角形内角和等于两直角**。
- **存在矩形**，即存在四个角都是直角的四边形。
- **存在两个相似而不全等的三角形**，即形状可以放大缩小而不变形。

每一条都可以从第五公设推出，也都可以在其余公设之下推出第五公设。它们是同一条假设的不同外衣。

## 边界

这不是说这些尝试都很笨。恰恰相反，它们失败的方式高度一致，而这个一致性本身是有信息量的：反复失败暴露的不是技巧不足，而是**目标不成立**。

也要注意这个结论的限度。等价性说明现有的路走不通，它并没有证明第五公设不可能从其余公设推出。「不可能」是一个更强的断言，需要完全不同的手段，那要等到有了模型才做得到。

## 为什么这个诊断难做

诊断难在证明者往往看不见自己用了什么。「形状可以放大缩小」这种假设太像常识，写证明的人不会觉得它是一个假设。要发现它，必须逐句核对每一步的许可来源——和你在命题 1 里找出交点那一句用的是同一个动作。

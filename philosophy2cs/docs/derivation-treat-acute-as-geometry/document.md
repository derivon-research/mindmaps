# 矛盾长期不出现，本身需要一个解释

**问题压力（历史与逻辑）**：锐角假设下的推演已经积累了一大批定理，全都相容，没有一条撞上矛盾。这个状态本身要求解释。有两种读法，而且必须选一个。第一种：矛盾还在更深处，推得不够远，继续推。第二种：矛盾之所以没出现，是因为根本没有矛盾可推，这条路不通往荒谬，它通往一门几何。

第一种读法有一个致命的实际问题：它无法被证伪，也无法被完成。推一百条定理没出矛盾，可以说推得不够远；推一千条也可以这么说。按这种读法工作，永远拿不到结论。萨凯里最后要靠「与直线的本性相悖」这种非形式的理由收场，正是这个困境的表现。

**解决动作**：改采第二种读法，并且把它变成实际工作——不再把这些定理当作反证过程中的中间产物，而是把锐角假设立为公理，为这个体系建设它自己的内容。罗巴切夫斯基与波尔约各自独立走了这一步，为这门几何建立了三角学与面积理论，使它成为一门可以持续研究的学科而不是一堆怪例。

这个动作的实质是身份转换，不是新的推演。同一批定理，在萨凯里手里是待驳倒的怪结论，在这里是这门几何的定理。转换之所以合法，是因为反证纲领已经交付了它能交付的全部东西：它穷尽了情形，堵掉了钝角，而在锐角情形上停摆了。停摆不是暂时的技术困难，它是这条路的终点。

本步只用一个前提，就是锐角假设下那个连贯的定理体系。没有它，这个决定没有对象；有了它，转换才只是重新解释既有材料。

## 来源与范围

Lobachevsky 1829–1830 年的喀山出版物，其地位见 Milnor, "Hyperbolic geometry: the first 150 years"（*Bull. AMS*, 1982）；János Bolyai, *Appendix*，附于 *Tentamen*（1832）；高斯的相关通信见 MacTutor 传记与 *Bull. AMS* 的通信综述。

必须保留的不确定性：本条把「矛盾不出现需要解释」写成问题压力，这是逻辑重构。历史上三人各自的路径不同，也没有证据表明他们读过萨凯里——那本书直到十九世纪中叶才被贝尔特拉米重新发现。因此这一步是逻辑上的承接，不是影响史上的承接。

## 权重理由

权重 3.0，暂定值。技术含量低，难点全在观念上：要看出「继续等矛盾」是一条无法完成的路，并接受同一批定理可以在不作任何新推演的情况下改变身份。这是一次非显然的重新解释。该值尚未由学习者的实际用时校准，属于 provisional。

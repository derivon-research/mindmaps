# 自明性标准一旦确立，第五公设就通不过它

**问题压力（历史）**：如果公设之所以能当起点是因为它自明，那么这个标准就可以拿来逐条检验清单本身。检验一做，第五公设立刻掉队。它的陈述要占满一整段，而且要求判断两条直线在无限延长之后是否相交——这个操作没有人能执行，也没有人能在有限的图上看完。相比之下，前四条都是可以当场作出或当场认可的。古代已经有人注意到这个落差：波西多尼乌斯、托勒密、普罗克洛斯等人都试图证明它或换掉它。欧几里得自己的写法也暴露了同样的不安，第一卷前 28 条命题一律不用它。

**解决动作**：普罗克洛斯把这个落差转成一个明确的结构性主张——第五公设的**位置**放错了，它应当从公设里删去，改为由其余起点证明的定理。他在评注中写下这一条"应当从请求之列中彻底抹去，因为它是一条包含许多疑点的定理"，并检查了托勒密的证明尝试，判定其不成立。这个动作没有质疑该命题为真，它只重新安排了它在体系中的位置，于是开出了一项延续两千年的研究纲领：从其余公设推出第五公设。

两个前提缺一不可。没有《几何原本》这个具体体系，就不知道被检验的是哪五条句子，也看不出第五条与其余四条在措辞上的差别。没有「[直觉的自明性作为公理的担保](../concept-intuition-warrants-axioms/index.html)」这个立场，落差就只是文风长短的问题；正因为自明性被当成起点的资格证明，通不过它才意味着资格不足。

## 来源与范围

Proclus, *Commentary on the First Book of Euclid's Elements*，Thomas Taylor 1792 年英译（TCD 转录本，论公设一节）；MacTutor "Proclus on the Parallel Postulate"；MacTutor "Non-Euclidean geometry" 关于前 28 条命题的说明。

不确定性：把「自明性是公设的资格标准」当作一条明文标准，是本图前一步建立的立场重构，古代作者没有这样系统地表述过。普罗克洛斯的实际论证更多诉诸「疑点」与已有的证明尝试，而不是一个成文的判据。

## 权重理由

权重 2.0，暂定值。学习者已经掌握了自明性标准，本步只是把它应用到清单上并读出差别，方法选择很少。难度在于接受「位置错了但内容为真」这种判断，而这一点在[第一原理](../concept-first-principle/index.html)的边界里已经练过。该值尚未由学习者的实际用时校准，属于 provisional。

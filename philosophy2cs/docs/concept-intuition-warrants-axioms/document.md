# 直觉的自明性作为公理的担保

这是一个关于"起点凭什么为真"的立场：公设与公理之所以可以被接受，是因为我们对空间和图形有直接把握，看懂它说的是什么就同时看出它为真。按这个立场，直觉是公理的担保人，公理只是把直觉的内容写成了句子。

在这个立场里，"从任一点到任一点可以作一条直线"之所以不需要证明，不是因为大家约定不证，而是因为任何理解这句话的人都能在纸上或心里做出这条线。同样，"整体大于部分"被当作无需论证的共同概念。

这个立场把知识的次序确定下来了：直觉在先，公理化在后。公理体系是对已经把握的东西的整理和记录，它的正确性依附于直觉，而不是反过来给直觉立法。这个方向在十九世纪会被反转，那是后面的事。

## 边界

要把它与三个相邻立场分开。

它不同于"公理是约定"：约定论认为起点是自由选择的，选别的也行；这个立场认为起点是被看出来的，看错了就是错。

它不同于"公理是经验概括"：经验概括来自反复测量并且可以被新观测推翻；这个立场认为自明性不靠积累观察。

它也不同于"公理只是形式符号串"：那要等到形式公理化之后才成为可能的看法。

## 一个提前的裂缝

《几何原本》的第五公设（平行公设）陈述冗长，不像其他公设那样一看即明。古代已有人认为它应当被证明而不是被假定。这条裂缝说明"自明性"在这个体系内部并不是均匀分布的。

## 来源与范围

Euclid, *Elements* 第一卷的公设与共同概念（Heath 英译本）；Reviel Netz, *The Shaping of Deduction in Greek Mathematics* (Cambridge, 1999) 关于带字母的图作为希腊演绎实践核心载体的论点。

不确定性需要明说：欧几里得本人没有为公设提供认识论辩护，《几何原本》里没有一句话说"这些是自明的"。把"直觉自明性"当作公理的担保，主要是后世注家与近代哲学（尤其是把几何当作先天知识样板的传统）对希腊实践的解释。本文因此把它标为一个**立场**，而不是欧几里得的自述。

# 非欧几何：锐角假设被当作一门独立几何来发展

这是一个决定，也是决定的产物：不再把锐角假设看成通往矛盾的中途站，而是把它当作一门几何的公理，系统地建设它。作出这个决定的人不再等待矛盾，他们开始为这门几何建立三角学、面积公式和完整的命题体系。

在这门几何里，过直线外一点存在不止一条不与之相交的直线，三角形内角和小于两直角，亏损与面积成比例，相似而不全等的三角形不存在，因而图形的大小与形状不再彼此独立。这些正是萨凯里推出来的那批定理，只是它们的身份变了：从「等待被推翻的怪结论」变成「这门几何的定理」。

## 谁作出了这个决定

罗巴切夫斯基在 1829 至 1830 年间于喀山的一份地方刊物上发表了相关工作，这通常被认作非欧几何公开文献的起点。波尔约·亚诺什的《Appendix》作为其父《Tentamen》第一卷的附录于 1832 年问世，独立达到了同样的结论。高斯在私人信件中表明他很早就得到过类似结果，但生前没有发表，他在 1832 年读到波尔约的《Appendix》后才对外表态。

## 边界

必须把这门几何和它的地位分开。到这一步为止，被建立的是**一套定理体系**，不是「这套体系不含矛盾」的证明。发展得再完整，也仍然可能在更深处藏着矛盾——这正是萨凯里当年期待的东西。相容性要等模型出现才被解决。

也不要把它读成「欧氏几何错了」。这门几何不否定欧氏几何的任何定理，它换掉了一条公设，得到另一个体系。两者是并列的，不是对错关系。

真正被这个决定改变的是**可能性的数量**。在此之前，几何只有一种，它描述我们所在的空间。在此之后，几何至少有两种，而哪一种描述我们所在的空间，变成了一个需要另行回答的问题。

## 来源与范围

Lobachevsky 1829–1830 年发表于喀山刊物的工作，其作为非欧几何文献起点的地位见 Milnor, "Hyperbolic geometry: the first 150 years"（*Bull. AMS*, 1982）；János Bolyai, *Appendix scientiam spatii absolute veram exhibens*，附于 Farkas Bolyai 的 *Tentamen*（Maros-Vásárhely, 1832）；高斯的态度见其与 Gerling、W. Bolyai 等人的通信，相关整理见 MacTutor 的 Bolyai 传记与 *Bull. AMS* 关于高斯几何基础通信的综述。

不确定性：波尔约《Appendix》的年份在文献中有 1831 与 1832 两种记法，前者指抽印本印出的时间，后者指随《Tentamen》正式出版的时间。三人各自独立到达结论的先后与相互影响，历来有争议，本文不作裁定。

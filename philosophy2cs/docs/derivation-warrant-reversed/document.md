# 两个互相冲突的体系同样无矛盾，直觉因此失去裁决权

**问题压力（逻辑）**：相对相容性的结论把一个旧立场逼到了绝境。原来的立场说，公理为真是因为它自明，直觉是担保人，公理体系是直觉的记录。现在的事实是：存在两个互相冲突的几何体系，第五公设在一个里面成立、在另一个里面不成立，而它们的无矛盾性绑在一起，只要欧氏几何站得住，非欧几何就同样站得住。直觉只认其中一个。问题于是无法回避——直觉不接受的那一个，凭什么被判出局？

**解决动作**：检查直觉在这里还能做什么，结论是它做不了裁决。它给不出形式矛盾，因为矛盾已被证明不存在；它给出的只是不适，也就是萨凯里那句"与直线的本性相悖"。而那句话现在有了确定的评价：它当年就是错的。锐角几何并不荒谬，抗议它的直觉才是不可靠的向导。一个在关键案例上判错、又拿不出可核对理由的东西，不能充当为真的根据。

于是担保关系必须撤销，而撤销之后空位必须有人填。剩下的候选只有体系自身可核对的性质——这组公理是否推出矛盾，某一条是否被其余几条蕴涵，它们刻画的结构是否唯一。这些性质有一个共同特点：检查它们不需要知道"点"和"直线"指的是什么，只需要检查公理之间的形式关系。贝尔特拉米的模型已经示范了这一点，他把"点"指派给曲面上的点、把"直线"指派给测地线，推理照样有效。含义可以更换，结构不变。

方向就此反转。原来是直觉在先、公理是记录；现在是公理体系在先、划定一类结构，而空间直觉至多是其中一个熟悉的实例。

两个前提缺一不可。没有相对相容性这个结论，"非欧几何也许藏着矛盾"这条退路就还开着，直觉可以继续等待矛盾出现而不必交权。没有「[直觉的自明性作为公理的担保](../concept-intuition-warrants-axioms/index.html)」这个立场，就没有需要被撤销的东西——本步的产物是一个立场对另一个立场的替换，被替换的那个必须在场。

## 来源与范围

事实依据见贝尔特拉米 1868 年的模型与相对相容性结论，以及萨凯里 1733 年对锐角假设的结论措辞。本条的论证由本文重构。

必须保留的不确定性：这个反转在历史上没有单一时刻，也没有一份宣言。它是十九世纪末至二十世纪初逐步形成的共识，不同数学家的接受程度差异很大。本条把它写成一次可辨认的立场替换，是为后续发展提供明确起点的教学重构，不是某位作者的自述。

## 权重理由

权重 3.5，暂定值。技术已经在前一步付清，这里的成本全在观念上，而且是本段最容易口头接受、实际未消化的一步。学习者要真正放弃"总有一个几何是真的空间"这个预设，接受直觉在一个关键案例上判错，并看出空位只能由体系自身的形式性质来填。最后一点是通往形式公理化的门，值得单独确认。该值尚未由学习者的实际用时校准，属于 provisional。

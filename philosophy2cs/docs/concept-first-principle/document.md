# 第一原理

第一原理是一门演绎科学中不再继续证明的起点。它不是"暂时还没证明"的命题，而是按这门科学的结构就不该由更基本命题推出的命题。

亚里士多德在《后分析篇》中把这类起点称为 archai，并列出它们的特征：为真、初始（primitive）、直接（immediate，即中间没有可插入的推理环节）、比由它推出的东西更为人所知。他还把起点分成两类：一类是各门科学共用的公理（common axioms），一类是某门科学专有的起点。

## 边界

第一原理与定理的区别在于位置而不在于难度。一条容易的命题如果由更基本的命题推出，它仍是定理；一条内容丰富的命题如果被选作不再证明的起点，它就是第一原理。

这里有一个常见的误判：把平凡的命题当成"应该能推出来"的命题。判据不是这条命题看起来多显然，而是**在这个体系里它下面还有没有更基本的东西**。等量传递就是例子。"与同一个量相等的量彼此相等"平凡到几乎不像一条命题，但欧几里得把它列为共同概念 1，即不再证明的起点。原因是这个体系里没有比它更基本的东西可以用来推它：证明本身就要靠等量替换，用等量替换去证等量替换会构成循环。命题越平凡，往往越可能是起点而不是定理。

第一原理与"假设"的区别在于地位。假设可以随时撤回或替换，而古典传统中的第一原理被认为是这门科学为真的根据。

这个概念本身不回答一个关键问题：起点为真的根据是什么。那属于另一个理解状态（见"[直觉的自明性作为公理的担保](../concept-intuition-warrants-axioms/index.html)"）。

## 来源与范围

亚里士多德《后分析篇》I.2（71b19–25）关于 archai 的特征；SEP "Aristotle and Mathematics" 第 2 节关于演绎科学的第一原理结构。等量传递的例子取自 Euclid, *Elements* 第一卷共同概念 1，原文作 "Things which equal the same thing also equal one another"（Heath 英译，Clark University / Purdue 整理本）；本文使用的 a=b 且 b=c 推出 a=c 的形式与原文措辞在等号对称性下等价，不是欧几里得的原句。

不确定性：亚里士多德对起点的分类（定义、公理、假设、公设）在不同段落与不同注家那里划法不完全一致，本文只保留"不再证明的起点"这一共同核心。

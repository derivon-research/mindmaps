# 普罗克洛斯：第五公设应当被证明而不是被假定

这是一个关于欧几里得起点清单的具体主张：第五公设不该留在公设里，它应当作为定理被证明出来。持这个主张的人不反对它为真，反对的是它的**位置**。

普罗克洛斯在五世纪写的《〈几何原本〉第一卷评注》中给出了这个判断。Taylor 1792 年英译本的措辞是：这一条"应当从请求（Petitions）之列中彻底抹去，因为它是一条包含许多疑点的定理"。他还记录了托勒密为证明它所作的尝试，并指出该尝试不成立。

## 主张的理由

理由是自明性的落差。前四条公设可以当场执行或当场认可：从一点到一点作直线、延长线段、以任意心和半径作圆、凡直角相等。第五条不是这样的：它要求判断两条直线在**无限延长之后**是否相交。没有人能执行这个操作，也没有人能在图上看完它。一个必须靠推理才能接受的句子，按前四条建立起来的标准，就不该被列为无需推理的起点。

欧几里得本人的写法也支持这个观察：《几何原本》第一卷的前 28 条命题都不使用第五公设，他把它的使用推迟到了不能再推为止。

## 边界

这个主张不是「第五公设是假的」，那要再过一千三百年才有人认真设想。它也不是「第五公设不重要」。它主张的是一件很有限的事：这条句子的地位被放错了，它属于定理那一侧。

要把它和后来的怀疑区分开。普罗克洛斯这一派相信欧氏几何是唯一的几何，他们要做的是让这座建筑更干净，而不是动摇它。这个纲领的失败方式，才是后面故事的开端。

## 来源与范围

Proclus, *Commentary on the First Book of Euclid's Elements*，Thomas Taylor 1792 年英译（Trinity College Dublin 转录本，论公设一节）；MacTutor "Proclus on the Parallel Postulate" 与 "Non-Euclidean geometry" 条目关于前 28 条命题不依赖第五公设的说明。

不确定性：普罗克洛斯生活在欧几里得之后七百余年，他的评注是现存关于早期证明尝试的最早来源，但并不完整。波西多尼乌斯、托勒密等人的原始论证多数只能通过他的转述得知。他自己也提出过一个证明，同样不成立，本文不展开。

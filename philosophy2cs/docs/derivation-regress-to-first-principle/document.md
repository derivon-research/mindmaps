# 无穷倒退迫使演绎科学承认不再证明的起点

**问题压力（历史与逻辑）**：如果认识一个命题必须靠从更为人所知的前提论证它，那么这些前提本身也要被认识，于是它们同样需要论证。这个要求可以无限重复。亚里士多德在《后分析篇》第一卷第三章面对的正是这个困境，他讨论了当时两种回应：一种认为知识因此根本不可能，因为论证会无穷倒退；另一种认为可以循环论证，让命题互相支撑。

**解决动作**：亚里士多德拒绝了这两条出路。无穷倒退使论证永远无法完成，因此没有任何命题真正被认识；循环论证则要求一个命题既先于自身又后于自身，这与"前提必须比结论更为人所知"直接冲突。于是只剩第三条路：论证链必须终止在一些**直接的**命题上，它们不再由更基本的命题推出，其为真也不靠论证。这些终点就是[第一原理](../concept-first-principle/index.html)。

这一步只用到了"[论证性知识](../concept-demonstrative-knowledge/index.html)"这一个前提：正是"必须由更为人所知的前提推出"这条要求本身产生了倒退，也正是它排除了循环。结论不预设起点已经存在，而是证明了不承认起点就得放弃知识。

## 来源与范围

亚里士多德《后分析篇》I.2–I.3；SEP "Aristotle's Logic" 与 University of Washington 关于 Posterior Analytics 的讲义（archai 的特征列表）。

不确定性：亚里士多德如何**认识**第一原理（《后分析篇》II.19 的归纳与 nous）是另一个有争议的问题，本条推导不涉及。

## 权重理由

权重 3.0，**观察值**（曾因一次判别失误上调至 3.5，现根据新证据改回）。倒退论证的结构不是显然的：要看出"论证要求"本身既制造了倒退又封死了循环，需要一次非平凡的观察。

证据分两步。学习者首次应用这个判据时失误：把等量传递归为"推出来的性质"，而欧几里得把它列为共同概念 1。但在概念文档补充了"平凡≠可推出"的边界之后，学习者无需提示就用直接性、更为人所知、初始性这三条特征，正确判定了一个全新案例（为何等边三角形作图是命题而不是公设）。

因此首次失误的原因应归于概念文档的边界写得不够可用，而不是本步本身的固有难度。文档修复后，本步对该学习者的实测成本回到 3.0：倒退论证仍需要一次非显然的观察，但不需要反复点拨，也不需要新技术。

# 直觉不再能担保公理

这是一个立场的失效声明：公理为真的根据不能是直觉的自明性。它取代了本图开头确立的那个立场，方向正好相反。

理由是一个已经被证明的事实。欧氏几何与非欧几何互相冲突——在一个里面过线外一点恰有一条平行线，在另一个里面有无穷多条——而它们同生共死，只要一个无矛盾，另一个就无矛盾。直觉只支持其中一个，却无法把另一个判为不成立。于是直觉在最关键的问题上失去了裁决权：它分不出哪一个体系是可用的，因为两个都可用。

## 直觉还剩下什么

它没有被赶出数学，它被降级了。直觉仍然是发现的来源、理解的手段、选择研究方向的向导。它不再是**为真的根据**。

这个降级带来一个连锁后果。既然直觉不能担保起点，起点就必须靠别的东西站住。剩下的候选只有体系自身的性质：这组公理会不会推出矛盾，某一条能不能被其余几条推出，它们描述的结构是否唯一。检验这些性质不需要看清楚公理"说的是什么"，只需要检查符号之间的关系。公理化从此可以脱离含义来进行。

## 与前一个立场的对照

原来的次序是：直觉在先，人先把握空间，公理体系把把握到的东西记录下来，正确性从直觉流向公理。

现在的次序是：公理体系在先，一组公理划定一类结构，直觉至多是这类结构的一个熟悉实例。正确性不再从直觉流入，而是由体系自身的相容性、独立性来确定。

## 边界

这不是说欧氏几何被推翻了。它的每条定理仍然成立，它仍然是描述日常空间的极好模型。变的不是它的内容，是它的**地位**：它从"唯一的、由直觉担保的几何"变成"多种几何中的一种"。

也不要把它读成「直觉不可靠」。萨凯里的例子说明的恰恰是更微妙的事：直觉在锐角几何面前发出了强烈抗议，而抗议的内容是错的。可靠与否不是重点，重点是它不再有资格作判决。

这个立场留下了一个尚未回答的问题：如果公理不靠直觉担保，那么一份公理清单要满足什么条件才算合格。回答它需要把「相容性」「独立性」「完备性」变成可以处理的技术问题，那是希尔伯特的工作，尚未进入本图。

## 来源与范围

本条是对前述发展的立场归纳，它的事实基础是贝尔特拉米 1868 年模型给出的相对相容性结论（见相关概念与推导），以及罗巴切夫斯基与波尔约建立的非欧几何内容。

不确定性：这个立场的转变在历史上是渐进的，并非在 1868 年由某一位作者一次宣布。相关的哲学后果在十九世纪末到二十世纪初持续发酵，不同数学家接受的程度差异很大。本文把它写成一个可辨认的立场，是为了让后续发展有一个明确的出发点，不主张存在一个转变的时刻。
